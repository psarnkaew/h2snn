Motivation

Problem: Heterogeneous Graphs

Real-world graphs have multiple node types and relation types (e.g., Papers, Authors, Subjects in ACM).

Problem: Heterophily

Connected nodes often have different labels. Standard message passing over-smooths dissimilar neighbors.

Existing Gap

Most HGNNs project to homogeneous meta-path views — losing cross-type edge structure and ignoring higher-order topology.

H²S-NN Solution

Lift the graph to a typed 2D cellular complex, learn relation-specific sheaf maps, and diffuse via Hodge operators.

Problem Setting

Input: Heterogeneous Information Network

$$G = (V,\; E,\; \varphi: V \to \mathcal{T}_V,\; \psi: E \to \mathcal{R},\; X)$$

  • $E$ — directed typed edges, relation set $\mathcal{R}$
  • $x_v \in \mathbb{R}^{d_{\text{raw}}(\varphi(v))}$ — type-specific features
  • $Y_{\text{lab}}$ — labels on target node type $\tau^*$

Stage 0 — Node Encoding (STAGE)

Type-specific Linear Encoder

$$h_v^{(0)} = W_{\varphi(v)}\, x_v + b_{\varphi(v)}$$
  • Separate weight $W_\tau$ per node type $\tau$
  • Projects to uniform dimension $d$ across all types
  • Acts as plug-in slot for pre-trained STAGE encoder

Output

$$H^{(0)} \in \mathbb{R}^{N \times d}$$

All node embeddings now share the same stalk dimension $d$, regardless of original feature type or size.

Stage 1 — Lifting to a 2D Cellular Complex

Three Cell Types

LevelCellsCount
$X^0$Nodes $V$$N$
$X^1$Edges $E \cup \bar{E}$ (+ closure)$M + F$
$X^2$Meta-path instances (faces)$F$

Closure edges $\bar{e}_f$ close each meta-path into a valid boundary loop — required by CW-complex topology

Meta-path Face Example

PAP face

$v_0 \xrightarrow{r_1} v_1 \xrightarrow{r_2} v_2$

+ closure edge $\bar{e}_f = (v_2 \to v_0)$

Boundary: $\partial f = (e_1, e_2, \bar{e}_f)$ — closed loop ✓

Closure Edge Maps (frozen)

$$F^{\text{src}}_{\bar{e}} = \lambda_{\text{close}} I,\quad F_{{\bar{e} \triangleright f}} = 0$$

$\lambda_{\text{close}} = 10^{-6}$ — topologically required but contributes nothing to diffusion

Stage 2 — Directed Typed Cellular Sheaf

Node-to-Edge Restriction Maps

For edge $e = (u \xrightarrow{r} v)$:

$$F^{\text{src}}_{u \triangleright e} = \text{MLP}_r^{\text{src}}\bigl([h_u \| h_v \| z_r^{\text{rel}}]\bigr) \in \mathbb{R}^{d \times d}$$
$$F^{\text{tgt}}_{v \triangleright e} = \text{MLP}_r^{\text{tgt}}\bigl([h_u \| h_v \| z_r^{\text{rel}}]\bigr) \in \mathbb{R}^{d \times d}$$
  • Separate MLP pair per relation type $r$
  • Optionally projected to orthogonal group

Edge-to-Face Restriction Maps

Position-aware via LSTM over boundary edge tokens:

$$t_i = [h_{\text{src}(e_i)} \| h_{\text{tgt}(e_i)} \| \text{emb}(\tau_E(e_i)) \| \text{emb}(i)]$$
$$F_{e_i \triangleright f} = \text{MLP}_F\!\left(\text{LSTM}(t_1, \ldots, t_\ell)_i\right)$$

LSTM captures path-order context; each edge gets a unique face map

Key advantage: Directed sheaf separates "source propagation" from "target reception" — enables fine-grained heterophilic message control

Stage 3 — Coboundary Operators

$\delta_0$: Nodes → Edges

$$(\delta_0\, x)_e = F^{\text{tgt}}_{v \triangleright e}\, x_v - F^{\text{src}}_{u \triangleright e}\, x_u$$

Measures disagreement between node signals projected into the edge stalk.
When $\delta_0 x = 0$ on all edges, $x$ is globally consistent (harmonic).

$\delta_1$: Edges → Faces

$$(\delta_1\, s)_f = \sum_{e_i \in \partial f} F_{e_i \triangleright f}\, s_{e_i}$$

Aggregates edge signals around a face boundary.
Closure edges contribute zero (frozen $F = 0$).

Coboundary condition: $\;\delta_1 \circ \delta_0 = 0\;$ — guaranteed by construction with closure edges and consistent orientations

Stage 4 — Hodge Laplacians

Node Laplacian $L_0$

$$L_0 = \delta_0^\top \delta_0 \;\in\; \mathbb{R}^{Nd \times Nd}$$

Acts on node cochains.
$\ker(L_0)$ = globally harmonic node signals.

Edge Laplacian $L_1$

$$L_1 = \delta_0\, \delta_0^\top + \delta_1^\top \delta_1 \;\in\; \mathbb{R}^{Md \times Md}$$

Two terms: node–edge consistency (lower) + edge–face coherence (upper).

Efficient Application (never materialize)

$$L_0\, x = \delta_0^\top(\delta_0\, x)$$
$$L_1\, s = \delta_0(\delta_0^\top s) + \delta_1^\top(\delta_1\, s)$$

Hodge Decomposition

$\ker(L_1) = $ harmonic edge signals
= signals neither caused by nodes
  nor inconsistent across faces

Stage 5 — Hodge Diffusion

Initialization

$$x^{(0)} = H^{(0)} \in \mathbb{R}^{N \times d}$$
$$s^{(0)} = \text{MLP}_{\text{init}}([h_u \| h_v \| z_r^{\text{rel}}]) \in \mathbb{R}^{M \times d}$$

Euler Diffusion Steps

$$x^{(k+1)} = x^{(k)} - \eta_0\, L_0\, x^{(k)}$$
$$s^{(k+1)} = s^{(k)} - \eta_1\, L_1\, s^{(k)}$$

Run for $K$ steps. Stability: $\eta < 2/\lambda_{\max}$

Final Embeddings

$$x^* = x^{(K)}, \quad s^* = s^{(K)}$$

Intuition

Each step reduces Hodge "energy".
Node signals converge toward
harmonic representatives that
respect both local topology and
heterogeneous relational structure.

Step sizes $\eta_0, \eta_1$ are learnable (optional)

Stage 6 — Readout & Classification

Pool Edge Embeddings to Nodes

$$r_v^{\text{edge}} = \frac{1}{|\{e : e \ni v\}|}\sum_{e \ni v} s_e^*$$

Final Node Representation

$$z_v = \bigl[x_v^* \;\|\; h_v^{(0)} \;\|\; r_v^{\text{edge}}\bigr] \in \mathbb{R}^{3d}$$
  • $x_v^*$ — diffused harmonic node signal
  • $h_v^{(0)}$ — original STAGE embedding (skip connection)
  • $r_v^{\text{edge}}$ — pooled incident edge context

Prediction

$$\hat{y}_v = \text{MLP}_{\text{cls}}(z_v) \in \mathbb{R}^C$$

2-layer MLP with dropout and GeLU activation

Why three components?

Harmonic signal = global topology
STAGE skip = raw feature preservation
Edge pool = local relational context

Loss Function

Total Loss

$$\mathcal{L} = \mathcal{L}_{\text{CE}} + \lambda_0\|\delta_0 x^*\|^2 + \lambda_1\|\delta_1 s^*\|^2 + \lambda_c\|s^* - \delta_0 x^*\|^2$$

$\mathcal{L}_{\text{CE}}$

Cross-entropy on labeled target nodes $V_{\text{lab}}$

$\lambda_0 \|\delta_0 x^*\|^2$

Node-to-edge discrepancy — encourages harmonic node signals

$\lambda_1 \|\delta_1 s^*\|^2$

Edge-to-face smoothness — encourages coherent edge signals

$\lambda_c\|s^* - \delta_0 x^*\|^2$

Consistency term: final edge states should align with node-induced edge states

Warm-up strategy: train with $\mathcal{L}_{\text{CE}}$ only for first few epochs, then activate diffusion regularizers

Complete Forward Pass

  1. Encode nodes: $h_v^{(0)} = W_{\tau(v)} x_v + b_{\tau(v)}$
  2. Enumerate / sample meta-path instances → build $X^0, X^1, X^2$
  3. Add closure edges $\bar{E}$; frozen maps $F_{\bar{e}} = \lambda_{\text{close}} I$
  4. Learn node-to-edge restriction maps $F^{\text{src}}, F^{\text{tgt}}$ via relation MLPs
  5. Learn edge-to-face restriction maps $F_{e \triangleright f}$ via LSTM projector
  6. Assemble sparse coboundary operators $\delta_0, \delta_1$
  7. Initialize edge signals: $s^{(0)} = \text{MLP}_{\text{init}}([h_u \| h_v \| z_r])$
  8. Run $K$ Euler steps: $x^{(k+1)} = x^{(k)} - \eta_0 L_0 x^{(k)}$, $\;s^{(k+1)} = s^{(k)} - \eta_1 L_1 s^{(k)}$
  9. Pool incident edge embeddings to nodes: $r_v^{\text{edge}}$
  10. Classify: $\hat{y}_v = \text{MLP}_{\text{cls}}([x_v^* \| h_v^{(0)} \| r_v^{\text{edge}}])$
  11. Compute $\mathcal{L} = \mathcal{L}_{\text{CE}} + \lambda_0\|\delta_0 x^*\|^2 + \lambda_1\|\delta_1 s^*\|^2 + \lambda_c\|s^* - \delta_0 x^*\|^2$
  12. Backpropagate through all learnable modules

Key Design Choices

Orthogonal Restriction Maps

Maps parameterized via Householder reflections (default), Cayley transform, or matrix exponential — ensures stable Hodge diffusion and isometric projections

Directed vs. Undirected Sheaf

Separate source and target maps per edge allow asymmetric propagation — critical for heterophilic and directed relation modeling

Conformal Scaling

Optional per-edge learnable scalar: $F = \exp(\log s) \cdot O$ where $O$ is orthogonal — adds volume control without breaking orthogonality

Sparse Implementation

$L_0, L_1$ are never materialized; applied via two sequential sparse ops — scales to large graphs without $O(N^2d^2)$ memory

Orthogonal parameterization options: householder matrix_exp cayley euler

Module Design

StageEncoder

Type-specific linear encoders $W_\tau$ → uniform $\mathbb{R}^d$ embeddings

Typed2DComplexBuilder

DFS meta-path enumeration, closure edge injection, incidence structure

NodeToEdgeSheaf

Per-relation MLP pairs → restriction maps $F^{\text{src}}, F^{\text{tgt}} \in \mathbb{R}^{d \times d}$

EdgeToFaceSheaf

LSTM over boundary edge tokens → $F_{e \triangleright f} \in \mathbb{R}^{d \times d}$

CoboundaryDelta0 / Delta1

Sparse forward / adjoint passes for $\delta_0$ and $\delta_1$

H2SDiffusion

$K$ Euler steps on $L_0, L_1$; learnable $\eta_0, \eta_1$

NodeClassifier

Edge-to-node mean pooling → concatenate $[x^* \| h^{(0)} \| r^{\text{edge}}]$ → 2-layer MLP → logits
