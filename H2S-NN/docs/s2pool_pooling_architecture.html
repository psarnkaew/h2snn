The S2Pool Architecture

A GL(d)-invariant graph-level readout: instead of gauge-fixing node stalks to a learned anchor and attention-pooling them (as external SheafPool baselines do), S2Pool folds each node's and each edge's local state into a small basis-free projector, embeds it with a shared MLP, and mean-pools — once for the node branch, once for the edge (coboundary) branch.

Hi → stack → Xi → project → Pi → embed → zi → pool → τ0 → classify → logitsg

SUPERSEDED & BROKEN — historical record only (updated 2026-07-29). The finalized graph readout is SheafCovPool; see sheafcovpool_implementation.md. Separately, the projector this page describes is degenerate: P = XT(XXT)+X equals the constant identity I3 whenever X has full column rank, which is the normal case here (3 stacked views, d ≥ 3). With the thin SVD X = UΣVT, P = VΣUT(UΣ2UT)+UΣVT = VVT = I. So it carries no information about its input, every graph receives identical logits (measured: 1.5e-08 apart, where GramPool and SheafCovPool differ by ~2e-01), and the GL(d) invariance claimed below is invariance-by-constancy. Do not use S2Pool as a baseline. Note also that the node stack shown below sums raw edge coordinates across different edge stalks; the current code transports them through the endpoint restriction maps first.

1

Stack

Three existing d-dim vectors become columns of one small matrix — per node, per edge.

node iXi = [ x*i | h0i | pooled_edgesi ] ∈ Rd×3
edge eDe = [ δ0x*e | δ0h0e | s*e ] ∈ Rd×3
2

Project

Gram + Moore–Penrose pseudoinverse — invariant to any invertible basis change, no anchor or alignment step needed.

node iGi=XiXiT ∈Rd×d
Pi=XiTGi+Xi ∈R3×3
edge eQe=DeDeT → Pe=DeTQe+De
3

Embed

Flatten the 3×3 descriptor to 9 numbers, pass through one shared MLP per branch.

node izi = node_mlp( vec(Pi) ) ∈ Rhidden
edge ewe = edge_mlp( vec(Pe) ) ∈ Rhidden
4

Pool

Unweighted mean over the graph — permutation-invariant, no attention, no learned token.

nodes in gτ0 = meani∈Vg zi
edges in gτ1 = meane∈Eg we
5

Classify

Concatenate the two graph summaries, run one MLP head.

graph glogitsg = head( [ τ0 ‖ τ1 ] ) ∈ Rnum_classes

the node branch (τ0) and edge/coboundary branch (τ1) run in parallel through steps 1–4, and only meet here in step 5

Why a projector, not whiten + Procrustes?

SheafPool-style readouts remove scale/shear via whitening, then solve an orthogonal Procrustes problem against a learned anchor to fix the residual rotation — two steps, and only O(d)-invariant once the alignment succeeds.

S2Pool's projector Pi = XiT(XiXiT)+Xi is invariant to any invertible change of stalk basis in one step, with no anchor to learn and nothing to align.

Properties

GL(d)-invariant permutation-invariant no learned anchor reads C⁰ and δ₀

Pooling two branches means the classifier sees both the node section and the sheaf coboundary (edge disagreement) — SheafPool-style baselines only ever pool node stalks.

The S2Pool architecture. Graph-level readout for H2SNN processes node and edge state through five stages. (1) Stack assembles each node's and edge's three existing d-dim quantities into one small matrix. (2) Project forms the Gram matrix and its pseudoinverse to build a basis-free 3×3 descriptor, invariant to any invertible stalk reparameterisation. (3) Embed maps the flattened descriptor through a shared MLP. (4) Pool mean-aggregates each branch over the graph, unweighted and permutation-invariant. (5) Classify concatenates both branch summaries and runs a single MLP head to logits.
