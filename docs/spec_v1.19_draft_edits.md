## T-2 §6 Baselines — H2G-former's encoder as H2GB's configs
**Insert after:** `Hetero²Net stays (supervised; its masked terms are auxiliary losses).`
> (1.19, author) **H2G-former uses H2GB's own node-encoder stack.** On the H2GB datasets, exactly its configs (`gnn.node_encoder_name` of `configs/<dataset>/<dataset>-H2Gformer.yaml`, H2GB commit `d3b49db`): `Hetero_Raw+Hetero_Label+Hetero_Metapath` on ogbn-mag, mag-year, oag-chem, PDNS and H-Pokec; `Hetero_Raw+Hetero_Label` on IEEE-CIS-G, oag-cs and oag-eng; the label channel's masking and the MetaPath2Vec walk lists (`H2GB/loader/encoding_generator.py`) as H2GB's code. **Datasets without an H2GB config (author, 2026-11-13, option B):** the MetaPath2Vec channel is an on/off choice in H2G-former's search space (`metapath_pe` ∈ {on, off}), as H2GB itself enables it on some datasets and not on others; its walk schema is the dataset's meta-paths of HGB's published table that start at the target type (link prediction: those of the graph the task is derived from, starting at the target relation's head type — acm_pa ACM's paper paths, dblp_ap DBLP's author paths, imdb_ma IMDB's movie paths, freebase_bb Freebase's book paths; LastFM: HGB's user paths UU, UAU, UATAU), concatenated in the table's order into one cyclic schema, which is how H2GB builds its schemas (e.g. ogbn-mag, `encoding_generator.py:263-274`: APFPA, AIA, APPA concatenated); MetaPath2Vec settings as H2GB's (walk_length 64, context_size 7, walks_per_node 30, num_negative_samples 8, batch_size 128, lr 0.01; `encoding_generator.py:239-244`). Encoders: HGB node classification `Hetero_Raw+Hetero_Label` (+ `Hetero_Metapath` when on); link prediction `Hetero_Raw` (+ `Hetero_Metapath` when on; PubMed has no list: `Hetero_Raw` only); graph classification `Hetero_Raw` (TU has no list). The label channel reads training labels only (checked by an information-route test). Supersedes the adapter's restriction to `Hetero_Raw` (`src/baselines/adapters/h2gformer.py:19-25`).
