**Tests:** keep today's implementation as a test-only reference (`tests/`, not `src/`); on ≥ 20 random synthetic graphs (multi-edges, self-loops, facts stored in both orientations, isolated nodes, a featureless type) and random target sets with their mini-batch cells, every field of `ScopeMembers` and `ScopeBatch` is `torch.equal` to the reference; the index of an evaluation graph is built from that graph (two graphs, N6); all Part MB/MB-fix tests pass unchanged. **Cost (informational, not a gate):** time per target of both builders on one synthetic graph with 10⁶ facts, CPU, recorded with the command. **Mutation:** the index built without self-loop facts → the equality test fails.
