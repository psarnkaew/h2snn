1. โมเดลสุดท้ายในหนึ่งหน้า

1.1 ข้อมูลเข้า (ไม่เปลี่ยนจาก v2)

  • โหนด $v$ ชนิด $\phi(v)$, feature ตามชนิด (ชนิดไม่มี feature: embedding ตาม global id)
  • fact $e$ (D7: สองทิศที่เก็บนับเป็นหนึ่ง) ชนิด $\psi(e)$, บทบาทต้น/ปลาย
  • cell $f$ = path instance หนึ่งเส้นที่ WISP สุ่มได้ $f=(v_0,e_1,v_1,\dots,e_\ell,v_\ell)$ ไม่ซ้ำโหนด น้ำหนักสุ่ม $m_f$ (รวมต่อ anchor ใน mini-batch, M4)

1.3 เรขาคณิต (ไม่เปลี่ยน)

$$T_{v_0,f}=I,\quad T_{v_i,f}=T_{v_{i-1},f}\,F_{v_{i-1}\triangleleft e_i}^\top F_{v_i\triangleleft e_i},\qquad R_{e_i,f}=T_{v_{i-1},f}F_{v_{i-1}\triangleleft e_i}^\top$$

ทุกตัวเป็น orthogonal คำนวณแบบไม่สร้างเมทริกซ์ (Horner ตาม path) closure อยู่ในนิยามของ complex เท่านั้น (ทฤษฎีบท 1b)

1.4 energy (D-B0(b)) และ operator

$$E(Y)=\tfrac12\sum_{e\in E}a_e\sum_{v\in e}\|F_{v\triangleleft e}x_v-s_e\|^2+\tfrac12\sum_f\beta_f\Big[\sum_{e_i\in f}\|R_{e_i,f}s_{e_i}-z_f\|^2+\sum_{v\in f}\|T_{v,f}x_v-z_f\|^2\Big],\qquad L=\nabla^2E$$

แนวทแยงของ $L$ เป็นสเกลาร์คูณ $I$ เพราะทุก map เป็น orthogonal:

$$D_v=\sum_{e\ni v}a_e+\sum_{f\ni v}\beta_f,\qquad D_e=2a_e+\sum_{f\ni e}\beta_f,\qquad D_f=\beta_f(2\ell_f+1)$$

normalization (D-B3): $\hat L=D^{-1/2}LD^{-1/2}$ ทุก block แนวทแยงของ $\hat L$ เป็น $I$

1.5 การแก้ (D-B5) และการกำจัดตัวแปร (ทฤษฎีบท 7′)

$$Y^\star=\arg\min_Y\tfrac12\|x-h\|^2+\tfrac\tau2Y^\top\hat LY\iff MY^\star=P^\top h,\quad M=P^\top P+\tau\hat L\succ0$$
  • กำจัด (ทำบน $\hat L$ หลังนิยาม $D$ จากทุก fact): fact ที่อยู่บน cell 0 ตัว → เทอมตรงน้ำหนัก $\hat a_e/2$; fact ที่อยู่บน cell 1 ตัว → เทอมตรง $\frac{\hat a_e^2}{2\hat a_e+\hat\beta_f}$ + เทอมโหนด–cell เพิ่ม $\frac{\hat a_e\hat\beta_f}{2\hat a_e+\hat\beta_f}$ ที่ปลายทั้งสอง (น้ำหนักที่มีหมวกคือหลัง normalize) state บนเส้นเหลือเฉพาะ $E_{\text{shared}}$ = fact ที่อยู่บน cell ≥ 2 ตัว คำตอบ $x^\star,z^\star$ ไม่เปลี่ยน พิสูจน์ ตรวจ numpy 7e-16
  • PCG บน $M$ ที่กำจัดแล้ว preconditioner Jacobi $J=\mathrm{diag}(1+\tau$ ที่โหนด$,\ \tau$ ที่เส้นและ cell$)$ (หลัง normalize แนวทแยงเป็น $I$ จึงเป็นสเกลาร์คงที่) tolerance สัมพัทธ์ 1e-4, $T_{\max}=100$ เป็น stop condition (รายงาน ไม่ปรับ)
  • ค่าเริ่ม (D-B7): $x=h$, $s_e=\tfrac12(F_uh_u+F_vh_v)$, $z_f$ = ค่าเฉลี่ยของ $R_{e,f}s_e$ และ $T_vh_v$ บน f (ค่าดีที่สุดเมื่อ $x=h$; หนึ่ง UP)
  • batch: scope หลายตัวเป็น block-diagonal ⇒ dot product ($r^\top z$, $p^\top q$) และเกณฑ์หยุด**ต่อ scope** (segment-sum ตาม scope id; scope ที่ลู่เข้าแล้วถูก mask) จำเป็นต่อ M1 (prediction ของ target ไม่ขึ้นกับการจัด batch)
  • backward: $M\lambda=P^\top g$ แล้ว $\partial\mathcal L/\partial\theta=-\tau\,\lambda^\top(\partial\hat L/\partial\theta)Y^\star$ ผ่าน autograd ของสเกลาร์ $\lambda^\top\hat L(\theta)Y^\star$ ที่ตรึง $\lambda,Y^\star$ (รวม $\partial/\partial\tau=-\lambda^\top\hat LY^\star$) memory ไม่ขึ้นกับจำนวนรอบ พิสูจน์ (มาตรฐาน)

2.1 test ที่เหลือ (ตัดที่ไม่จำเป็นออกแล้ว; ทุกข้อเป็นพีชคณิต ไม่ใช่ประสิทธิภาพ)

  1. functoriality $R_{e_i,f}F_{v\triangleleft e_i}=T_{v,f}$ บน draw จริง
  2. matrix-free $\hat LY$ = dense บนกราฟเล็ก; สมมาตร; $\lambda_{\min}(M)>0$
  3. kernel: dim ker $\hat L$ = dim ker $\Delta_0$; free_cell_maps ยุบ
  4. ทฤษฎีบท 7′: กำจัดแล้ว $x^\star$ เท่าเดิม (fact บน 0 และ 1 cell)
  5. PCG ลู่เข้าหา dense solve; batch = ทีละ scope
  6. implicit gradient = finite difference และ = unroll ที่ลู่เข้าแล้ว (รวม $\partial/\partial\tau$)
  7. ทางเข้าโหนด: รบกวน $z_f$ อย่างเดียว → A7 เปลี่ยน; ไม่มี block ตรง $v_0$–$v_\ell$ ใน $M$ นอกจากผ่าน $z_f$ หรือ $s_e$
  8. แขน: hub_A = v2 $L_P$ + anchored solve (เทียบกับโค้ด v2 โดยตรง); no_path_cells = solve บนกราฟ
  9. (ไม่อยู่ใน card ฉบับ minimal) mutation: สลับ map ต้น/ปลาย, ลืม $\beta_f$ ใน $D$, local id กับชนิดไม่มี feature, dot product รวม batch แทนต่อ scope — ทุกข้อต้องมี test ที่ fail

หมายเหตุ: รายการนี้คือรายการตรวจความสมบูรณ์ของดีไซน์ ไม่ใช่ชุดเทสต์ที่ agent รัน ชุด gate จริงใน card (ฉบับ minimal 11 พ.ย.) มีเฉพาะ T1–T3, T7, T9, T10, T14 และ smoke IMDB 2 epochs ข้อที่ไม่มีเทสต์ (zero-block ของทางเข้าโหนด, hub_A = v2, mutation, batch หลาย scope) ยังไม่ได้ตรวจ

ตัดออก: gate zero-block, filter gain ≤ 1, Richardson, "K ที่ต้องใช้", hub dominance

4.4 เวลา ประมาณ

  • หนึ่งการใช้ operator: v1 = bmm $d\times d$ ต่อ edge ⇒ $E_{\text{dir}}d^2$ = 548k × 1,024 ≈ 0.56 GFLOP (δ₀) + δ₁ v3-B = factorized $O(kd)$ ต่อ incidence ⇒ (548k + 308k + 411k) × ~200 flop ≈ 0.25 GFLOP ต่อการใช้ — ถูกกว่า v1 ต่อครั้งราว 2 เท่า แม้มี incidence มากกว่า 2 เท่า
  • จำนวนการใช้: v1 = K·2 (L₀, L₁) ×2 (fwd+bwd) = 16; v2 = 4 × 2 = 8; v3-B = T × 2 โดย T จาก cond ของระบบเต็ม: toy (b) cond ≈ 11 ⇒ CG รัศมี $\frac{\sqrt{11}-1}{\sqrt{11}+1}=0.54$ ⇒ tol 1e-4 ใน ~15 รอบ ⇒ 30 การใช้
  • ประมาณ train step: v2 1.40 s ที่ 8 การใช้ (รวม overhead map/WISP ~0.5 s) ⇒ ~0.11 s ต่อการใช้ ⇒ v3-B ≈ 0.5 + 30 × 0.11 ≈ 3.8 s train + 0.94 s draw ≈ 4.7 s/epoch เทียบ v1 3.0 s (แต่ v1 มี instance แค่ 48k และ reviewer ก็ว่าช้า)
  • ทางลด (ไม่เปลี่ยน method): warm start จาก $Y^\star$ ของ epoch ก่อน (map เปลี่ยนช้า); tol 1e-3 ใน epoch แรก ๆ แล้วลดเป็น 1e-4 (บันทึกใน card เป็น schedule คงที่ ไม่ tune); และถ้ายังเกิน cost gate ใช้รูปตัด T คงที่ (= polynomial ดีกรี T ของ v2)
สรุปต้นทุนอย่างซื่อ: v3-B น่าจะใช้ memory ราว 1/6 ของ v1 และเท่า v2 (เพราะเก็บ graph ของการใช้ operator ครั้งเดียวแทน K ครั้ง) แต่ เวลาต่อ epoch น่าจะช้ากว่า v2 ราว 1.7 เท่า และอาจไม่เร็วกว่า v1 ตัวแปรที่ยังไม่ทราบคือจำนวนรอบ PCG บนกราฟจริง สิ่งที่ตอบ reviewer ได้โดยไม่ต้องรอ: (1) memory ของ v1 มาจาก $d\times d$ ต่อเส้น ไม่ใช่จาก cell (อ่านโค้ด) (2) v3-B มี memory ไม่ขึ้นกับความลึก (implicit) และ cond ของระบบโหนดไม่ขึ้นกับ N (พิสูจน์) (3) ตัวเลขจริงรอ C13
