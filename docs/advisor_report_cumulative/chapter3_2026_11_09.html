H2S-NN Revision: Heterophily of the Evaluation Datasets

How heterophilic is each dataset we evaluate on, measured the way the source benchmarks define it

9 November 2026Computed on CPU with the benchmarks' own published code

Why this chapter

The revised paper relates the model's gains to how heterophilic a dataset is. That comparison is only meaningful if every dataset is measured the same way. We therefore fixed two published measures and computed them with the reference code released by their authors, instead of writing our own versions. Before computing any new value, we checked that this pipeline reproduces a published number.

1. What the two measures capture

Both measures look at pairs of labelled nodes of the target type, for example two papers, that are linked through a meta-path: a short typed route such as paper–author–paper ("two papers share an author"). MLH (meta-path label homophily) is the share of such pairs whose two nodes carry the same label, averaged over all meta-paths of length two that start and end at the target type. We report it as heterophily, one minus that share. Higher means connected nodes disagree more often. The ℋ² index asks the same question but first subtracts the agreement that class sizes alone would produce if links ignored labels, and rescales the result (adjusted heterophily). A value near 0 means homophilic; near or above 1 means heterophilic. We use ℋ² as the primary measure because MLH can look homophilic merely because one class dominates.

A small example

Four papers P1–P4 have topics A, A, B, A. Two authors wrote them: author X wrote P1 and P2, author Y wrote P2, P3 and P4. Through "shares an author", including each paper with itself as the reference code does, there are 12 ordered paper pairs, and 8 of them agree on the topic. Agreement is 8/12 = 0.67, so MLH heterophily is 0.33, which looks homophilic. But topic A covers three of the four papers. When each paper is weighted by how many pairs it appears in, A accounts for 9 of 12 pair-ends and B for 3. Random pairing would agree with probability (9/12)² + (3/12)² = 0.625. The observed 0.67 is barely above that chance level: the adjusted homophily is (0.67 − 0.625)/(1 − 0.625) = 0.11, so ℋ² for this meta-path is 0.89, i.e. clearly heterophilic. The same links look homophilic to MLH and heterophilic to ℋ², because most of the agreement comes from class imbalance.

The values in the example are computed by hand. The reference code reproduces them exactly in our tests.

2. Check against a published value

Hetero²Net (Li et al., TPAMI 2025), which introduced MLH, reports for DBLP a homophily of 0.87 over its meta-path author–paper–author. Running the released code of ℋ²GB (Lin et al., KDD 2025), which defines ℋ², on the same public DBLP graph gives 0.872. We had fixed a tolerance of ±0.01 before running. The match depends on a detail: each author also counts as paired with itself, as in the released code. Without these self-pairs the value would be 0.80. The same pipeline also reproduces the published ACM value (0.60; ours 0.596) and IMDB value (0.24; ours 0.237). That paper's own ablation table lists these two values with the datasets swapped. Its main table and our results agree with each other.

Notes.

  • IMDB (multi-label). A movie can have several of five genres. We treat each genre as its own yes/no label, as the benchmark that released IMDB does. Both measures are computed per genre with the reference code and then averaged over the five genres. The whole-set comparison of section 2 (two movies agree only when their genre sets are identical) gives 0.763 and serves only as the check against the published value. The 359 of 4,932 movies without genres are handled as described for Freebase. Five different random labellings change the values by less than 0.003.
  • Freebase. Only one book in five carries a label. As in the reference code, every unlabelled book receives a random label, so our values are measured the same way as the published ones in this table. The graph is made two-way, as the benchmark's own loaders do. The random labels dominate the result. Counting only pairs of two labelled books gives an ℋ² index of 0.882 and an MLH of 0.478. That figure is a diagnostic, not the reported value. Five different random labellings change the ℋ² index by about 0.001.

4. Datasets without node labels: not measurable

Both measures compare the labels of linked nodes, so they need node labels.

  • LastFM (link prediction): users, artists and tags carry no labels, so the measures are not measurable.
  • PubMed (link prediction): the public release has no labels. The disease labels exist only in a separate release that is no longer publicly downloadable, so the measures are not measurable at present.
  • Graph-classification datasets: labels belong to whole graphs, not to nodes, so node-level heterophily does not apply. These datasets serve only to show that the model covers the task.
