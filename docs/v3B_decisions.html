0. คำศัพท์ (อ่านก่อน ทุกคำถูกใช้ด้านล่าง)

โหนด (node), เส้นจริง (fact), cell
โหนดคือสิ่งของในกราฟ (paper P1, author A7) เส้นจริงคือความสัมพันธ์หนึ่งรายการที่มีในข้อมูล (A7 เขียน P1) ข้อมูลที่เก็บสองทิศนับเป็นหนึ่ง cell (หรือ 2-cell, path cell) คือหน่วยหนึ่งหน่วยที่แทน path instance หนึ่งเส้นทั้งเส้น เช่น P1–A7–P9
meta-path กับ path instance
meta-path คือ "ชนิด" ของเส้นทาง เช่น PAP (paper–author–paper) path instance คือเส้นทางจริง เช่น P1–A7–P9 โมเดลของเรามี cell ต่อ instance ไม่ใช่ต่อชนิด
state
เวกเตอร์ $d$ ตัวเลขที่เก็บไว้ที่สิ่งหนึ่ง: $x_v$ ที่โหนด, $s_e$ ที่เส้น, $z_f$ ที่ cell รวมเป็น $Y=(x,s,z)$
map $F_{v\triangleleft e}$ (restriction map)
เมทริกซ์หมุนหรือสะท้อน ($F^\top F=I$ ความยาวไม่เปลี่ยน) ที่แปล state ของโหนด v ให้อยู่ใน "ภาษา" ของเส้น e เรียนรู้จากข้อมูล ขึ้นกับทั้งสองปลาย ชนิดเส้น และบทบาท (ต้น/ปลาย)
transport $T_{v,f}$
การหมุนต่อกันตามเส้นทาง ทำให้ state ของทุกโหนดใน path อยู่ในพิกัดของโหนดต้น $T_{v_0}=I$, $T_{v_i}=T_{v_{i-1}}F_{v_{i-1}\triangleleft e_i}^\top F_{v_i\triangleleft e_i}$ ไม่มีพารามิเตอร์ของตัวเอง map จากเส้นไป cell คือ $R_{e_i,f}=T_{v_{i-1},f}F_{v_{i-1}\triangleleft e_i}^\top$
sheaf, คู่ที่เทียบกันได้, Hasse diagram, covering pair
sheaf คือการติด state และ map ให้กับโครงสร้าง (โหนด ⊂ เส้น ⊂ cell) อย่างสอดคล้องกัน "σ อยู่ใต้ τ" (σ<τ) หมายถึง σ เป็นส่วนของ τ เช่น โหนด<เส้น, เส้น<cell, และโหนด<cell ด้วย Hasse diagram คือแผนภาพที่วาดเฉพาะคู่ที่ติดกันโดยไม่มีอะไรคั่น (covering pair: โหนด–เส้น, เส้น–cell) คู่โหนด–cell เทียบกันได้แต่ไม่ใช่ covering pair เพราะมีเส้นคั่น
energy, global section, kernel
energy คือตัวเลขเดียวที่วัดว่าสิ่งที่อยู่ติดกัน "ไม่เข้ากัน" เท่าไรหลังแปลด้วย map global section คือชุด state ที่ทุกคู่เข้ากันพอดี (energy = 0) kernel ของ operator $L=\nabla^2E$ คือชุดนั้นเอง ถ้า kernel เล็กลงเมื่อเพิ่ม cell แปลว่า cell "บังคับ" ข้อมูลให้ยุบ
กำจัดตัวแปร (Schur complement)
ถ้าให้ตัวแปรบางตัว (เช่น $s_e$) เป็นค่าดีที่สุดทันทีจากเพื่อนบ้าน แล้วแทนกลับ จะเหลือ energy บนตัวแปรที่เหลือซึ่งมีค่าต่ำสุดเท่าเดิม สูตรที่ใช้ซ้ำทั้งเอกสาร: สำหรับดาวที่มีจุดกลาง σ และเพื่อนบ้าน $y_i$ น้ำหนัก $w_i$
$$\min_\sigma \tfrac12\sum_i w_i\|y_i-\sigma\|^2=\tfrac{1}{2W}\sum_{i<j}w_iw_j\|y_i-y_j\|^2,\qquad W=\sum_i w_i$$
hub (ทาง A ของ v2)
วิธีคำนวณ cell ของ v2: ไม่มี state ที่เส้นและ cell cell ถูกแทนด้วยค่าเฉลี่ย $\bar z_f=\frac1{|f|}\sum_{v\in f}T_vx_v$ ที่คำนวณใหม่จากโหนดทุกครั้ง ตามสูตรข้างบนนี่คือการกำจัด $z_f$ ออกจากเทอม $\tfrac12\beta_f\sum_{v\in f}\|T_vx_v-z_f\|^2$
anchored solve
แทนการแพร่ทีละก้าว ด้วยการแก้ปัญหาเดียว: หา $Y$ ที่ทุกระดับสอดคล้องกันมากที่สุดโดยโหนดไม่หลุดจาก encoding $h$: $\min_Y \tfrac12\|x-h\|^2+\tfrac\tau2 Y^\top LY$ คำตอบคือ $MY^\star=P^\top h$, $M=P^\top P+\tau L$ ($P$ ดึงส่วนโหนด)
ความถี่ (frequency) ของ sheaf
eigenvector ของ operator โหนด $S$ ที่มี eigenvalue λ เล็ก = รูปแบบที่สอดคล้องกับ map (ความถี่ต่ำ) λ ใหญ่ = รูปแบบที่ขัดกันหลังแปล (ความถี่สูง) low-pass เก็บ λ เล็ก high-pass เก็บ λ ใหญ่ band-pass เก็บช่วงกลาง
gate, filter bank (ของ v2)
gate: ตัวคูณต่อโหนด $g_v$ (ฟังมากน้อย) $b_v$ (ส่งออกมากน้อย) ทำให้อิทธิพลไม่เท่ากันสองทิศ filter bank: ผสมผลการแพร่ 0…K รอบด้วยเมทริกซ์ $W_k$ ที่เรียนรู้ เพื่อเลือกความถี่ต่อพิกัด
normalization, degree $D$
$D_v=\sum_{e\ni v}a_e$ (+ส่วนจาก cell) คือ "น้ำหนักรวม" ของโหนด normalization คือการหารด้วย $\sqrt{D}$ ทั้งสองข้าง $\hat L=D^{-1/2}LD^{-1/2}$ เพื่อให้โหนดที่มีเพื่อนบ้านมาก (hub) ไม่ครอบงำ
condition number, PCG, implicit gradient
condition number ของ $M$ = eigenvalue สูงสุด/ต่ำสุด ยิ่งสูง ตัวแก้เชิงวนซ้ำยิ่งใช้รอบมาก PCG (preconditioned conjugate gradient) คือตัวแก้ระบบสมมาตรบวกแน่นอนที่ใช้แค่การคูณ $M$ กับเวกเตอร์ จำนวนรอบประมาณ $\sqrt{\text{cond}}$ implicit gradient คือการหา gradient ของ loss ผ่าน $Y^\star$ โดยแก้ระบบเดียวกันอีกครั้ง แทนการเก็บทุกรอบไว้
R2 W3
คำติด้าน method ข้อเดียวใน review: ใน v1 ข้อมูลจาก cell (face) ถึงโหนดผ่าน closure edge ซึ่งเป็นเส้นสมมติปลาย-ปลาย (P1–P9) จึง "ไม่ต่างจากวิธีที่ intro วิจารณ์" meta-review ยกซ้ำ

1. โมเดลที่กำลังตัดสิน และตัวอย่างกลาง

กราฟเล็ก: paper P1, P9, P4, author A7, subject S3 เส้นจริง $e_0$=(P1,A7), $e_1$=(A7,P9), $e_2$=(A7,P4), $e_3$=(P1,S3) WISP เดินสุ่มจาก P1 ได้ cell $f_1$=P1–A7–P9 (ผ่าน $e_0,e_1$) และ $f_2$=P1–A7–P4 (ผ่าน $e_0,e_2$) เส้น $e_3$ ไม่อยู่บน cell ใด

v3-B ตามเอกสาร v3B_design (ก่อนการตัดสินใจในเอกสารนี้): state ที่โหนด เส้น และ cell energy เป็นผลรวมบน covering pairs เท่านั้น

$$E_{\text{cov}}(Y)=\tfrac12\sum_{e}a_e\sum_{v\in e}\|F_{v\triangleleft e}x_v-s_e\|^2+\tfrac12\sum_f\beta_f\sum_{e_i\in f}\|R_{e_i,f}s_{e_i}-z_f\|^2$$

แล้วแก้ anchored solve อ่านผล $x^\star_v$ เข้าหัวทำนาย $\mathrm{MLP}([h_v,x^\star_v])$ น้ำหนัก $a_e=c_e^2$ (ต่อเส้น เรียนรู้จากสองปลาย) และ $\beta_f=w_fm_f$ (ต่อ cell: $w_f$ เรียนรู้จากทั้ง instance, $m_f$ จากการสุ่ม)

ข้อเท็จจริงที่พบวันนี้และเป็นต้นเหตุของการตัดสินใจครึ่งหนึ่ง พิสูจน์ ตรวจ numpy 7e-16

ถ้าเส้น $e$ อยู่บน cell $f$ เพียงตัวเดียว state $s_e$ ปรากฏในเทอมที่มีเพื่อนบ้านแค่ 3 ตัว คือ $F_ux_u$, $F_vx_v$ (น้ำหนัก $a_e$ ทั้งคู่) และ $z_f$ (น้ำหนัก $\beta_f$ หลังแปลง $R_{e,f}$ ซึ่งเป็น orthogonal จึงไม่เปลี่ยนความยาว) ใช้สูตรดาวในข้อ 0 โดยเขียนทุกอย่างในพิกัดของ cell ($R_{e,f}F_{v\triangleleft e}=T_{v,f}$):

$$\min_{s_e}(\cdots)=\tfrac12\frac{a_e^2}{2a_e+\beta_f}\|F_{u\triangleleft e}x_u-F_{v\triangleleft e}x_v\|^2+\tfrac12\frac{a_e\beta_f}{2a_e+\beta_f}\Big(\|T_{u,f}x_u-z_f\|^2+\|T_{v,f}x_v-z_f\|^2\Big)$$

ความหมาย: หลังกำจัด $s_e$ จะเหลือ (ก) เทอมเส้นตรงแบบ v2 แต่น้ำหนักลดจาก $a_e/2$ เป็น $a_e^2/(2a_e+\beta_f)$ และ (ข) เทอมโหนด–cell แบบ hub ของ v2 ที่มีน้ำหนักต่อโหนด $\kappa_v=\sum_{e\in f,e\ni v}\frac{a_e\beta_f}{2a_e+\beta_f}$ ดังนั้น บน fact ที่ไม่ถูก cell ใดใช้ร่วมกัน v3-B เท่ากับ hub ของ v2 บวก participation κ ทุกประการ (สคริปต์ b_vs_a.py: ต่าง 6.7e-16) สิ่งที่ B ทำได้แต่ hub ทำไม่ได้เหลือข้อเดียว: fact ที่ cell ≥ 2 ตัวใช้ร่วมกัน (เช่น $e_0$ ใน $f_1,f_2$) เป็นที่ที่ cell เหล่านั้นเขียนลง state เดียวกัน ทำให้เกิดการเชื่อมระหว่าง cell ที่ hub แยกกันไม่มี (ตรวจ: block P9–P4 ของ operator โหนดเท่ากับ 0.0029 ไม่เป็นศูนย์ แต่เล็ก)

สองผลที่ตามมาคือ D-B0 (เพดานน้ำหนัก) และทฤษฎีบท 7′ (กำจัดได้ → ลดต้นทุน) ด้านล่าง

ปัญหา

จากข้อ 1: น้ำหนักที่ cell ดึงโหนดได้ใน $E_{\text{cov}}$ คือ $\kappa_v=\sum_{e\in f,e\ni v}\frac{a_e\beta_f}{2a_e+\beta_f}$ ซึ่งเป็นฟังก์ชันเพิ่มของ $\beta_f$ แต่ มีเพดาน: $\lim_{\beta_f\to\infty}\kappa_v=\sum_{e\in f,e\ni v}a_e$ ขณะเดียวกันเทอมเส้นตรงลดเป็น $a_e^2/(2a_e+\beta_f)\to0$ ตัวอย่างตัวเลข ($a=1$ ทุกเส้น): $\beta=100$ ให้ $\kappa_{P1}=100/102\approx0.98$ และเทอมตรงของ $e_0$ เหลือ $1/102$ กล่าวคือ β ใหญ่ไม่ได้ "ขยาย" cell แต่ "ย้าย" fact จากการอ่านตรงไปอ่านผ่าน cell

ทำไมเป็นปัญหา

  • ขัดกับ R12 ของ spec ("ความแรงที่ instance ส่งถึงโหนดเป็นฟังก์ชันของทั้ง instance") ใน $E_{\text{cov}}$ ความแรงถูกจำกัดโดย $a_e$ ซึ่งเป็นฟังก์ชันของ คู่ (สองปลายของ fact) และใช้ร่วมโดยทุก cell บน fact นั้นและโดยเทอมตรง ดังนั้น $\beta_f$ เลือก ว่า fact ถูกอ่านผ่าน cell ไหน แต่ไม่กำหนด ขนาด ต่อ instance
  • ขัดกับ L11 ที่ Part K วัดไว้: หลักฐานชี้ขาดหนึ่ง cell ท่ามกลาง 64 ต้องได้ส่วนแบ่ง 0.45–0.87 ของ $D_v$ จึงถูกใช้ ใน $E_{\text{cov}}$ ส่วนแบ่งสูงสุดของ cell หนึ่งตัวใน $D_v$ คือส่วนแบ่งของ fact ของ v ที่อยู่บน path นั้น สำหรับ hub (subject ใน ACM ที่มี fact หลายพัน) ส่วนแบ่งนี้เล็กมากโดยโครงสร้าง ทางเดียวที่โมเดลหลบได้คือยก $a_e$ ของ fact นั้นให้สูงกว่า fact อื่นมาก ซึ่งกระทบทุก cell บน fact นั้นพร้อมกัน
  • กระทบ thesis H ("path instance ถือข้อมูลที่หายไปเมื่อยุบเป็นความสัมพันธ์ปลาย-ปลาย") และ C2 ladder ที่ทดสอบ H ผ่านช่องน้ำหนัก: ถ้าช่องน้ำหนักมีเพดานโดยโครงสร้าง การล้มของ C2 จะอธิบายไม่ได้ว่าเพราะ H ผิดหรือเพราะโมเดลพูดไม่ได้

พิสูจน์ว่าทฤษฎีบททั้งหมดคงอยู่ พิสูจน์

  • ทุกเทอมมีรูป $\|F_{\sigma\triangleleft\tau}y_\sigma-y_\tau\|^2$ สำหรับคู่ σ<τ ของ sheaf เดียวกัน (ทฤษฎีบท 1 ให้ $F_{v\triangleleft f}=T_{v,f}$ และ functoriality $F_{e\triangleleft f}F_{v\triangleleft e}=F_{v\triangleleft f}$)
  • $E=0$ ก็ต่อเมื่อทุกเทอมเป็นศูนย์ เทอมโหนด–เส้นเป็นศูนย์ ⇒ $\delta_0x=0$ และ $s_e=F_{v\triangleleft e}x_v$ จากขั้นที่ 3 ของบทพิสูจน์ทฤษฎีบท 3 (A_vs_B §9.3) ได้ $T_{v,f}x_v$ เท่ากันทุก v ใน f และ $R_{e,f}s_e=T_{v,f}x_v$ จึงมี $z_f$ หนึ่งค่าที่ทำให้ทั้งเทอมเส้น–cell และโหนด–cell เป็นศูนย์พร้อมกัน ⇒ $\ker L\cong\ker\Delta_0$ (ทฤษฎีบท 3 คงอยู่)
  • $M\succ0$ (ทฤษฎีบท 5) ใช้แค่ $L\succeq0$ และ $\ker L\cap\{x=0\}=\{0\}$ ซึ่งตามจากข้อบน ⇒ คำตอบเดียว ลู่เข้า
  • ทฤษฎีบท 8 (cell ถึงโหนดกลาง) แรงขึ้น: มีทางตรง $\beta_fT_{A7,f}^\top$ และทางผ่านเส้น; ไม่มีทางผ่าน closure (closure ไม่มี state)
  • ทฤษฎีบท 9 (WISP ไม่ลำเอียง): $L$ ยังเป็นเชิงเส้นใน $\beta_f$ ✓

4. D-B1 listen/broadcast gate

ปัญหา

v2 มี gate $\mathcal A=G\hat\Delta B$ เพื่อ R4 ของ spec ("โหนดฟังได้โดยไม่ส่ง ส่งได้โดยไม่ฟัง" ตัวอย่าง: subject ที่มี paper หลายพันควรบอก paper โดยไม่ถูกดึงไปหา paper แต่ละใบ") anchored solve ต้องการ $L$ สมมาตรและ PSD คำถาม: gate อยู่ร่วมกับ anchored solve ได้ไหม

ทำไมเป็นปัญหา พิสูจน์

$G\hat\Delta B$ ไม่สมมาตรเมื่อ $G\ne B$ จึง (i) ไม่ใช่ Hessian ของ energy ใด (Hessian สมมาตรเสมอ) ⇒ ปัญหา "หา $Y$ ที่ลด energy" ไม่มีนิยาม; (ii) บทพิสูจน์คำตอบเดียวใช้ $Y^\top MY=\|x\|^2+\tau Y^\top LY$ ซึ่งต้องการ $L\succeq0$ สมมาตร; (iii) PCG ต้องการ SPD; (iv) implicit gradient ใช้ $M=M^\top$ ไม่สมมาตรต้องแก้ $M^\top\lambda$ แยก (ทำได้แต่แพงสองเท่าและเสีย (ii)) spec Prop. 4 ของ v2 แก้เรื่องนี้ด้วย metric $BG^{-1}$ แต่ anchor term $\tfrac12\|x-h\|^2$ อยู่ใน metric มาตรฐาน สองเทอมจึงอยู่ใน metric ต่างกัน และผลรวมไม่เป็น energy ในทั้งสอง

สิ่งที่ยังทำได้: energy แบบมี gate ส่งออกอย่างเดียว $E_B(x)=\tfrac12(Bx)^\top L(Bx)$ สมมาตร (Prop. 4 เขียนไว้) แต่ (1) มันคือการคูณ map ของโหนด v ทุกตัวด้วยสเกลาร์ $b_v$ ซึ่งหลัง normalization (D-B3) ถูกดูดซับส่วนใหญ่ และ (2) ความไม่สมมาตร "ฟังโดยไม่ส่ง" ที่ R4 ต้องการจริงหายไปอยู่ดี (Prop. 4: detailed balance คือราคาของ energy)

5. D-B2 เลือกความถี่ได้ (filter bank ของ v2)

ปัญหา

spec R9: "การแพร่ต้องเลือกความถี่ต่ำ กลาง สูง ได้ต่อพิกัด เพราะใน heterophily ส่วนหนึ่งของสัญญาณอยู่ที่ความไม่ลงรอยหลังแปล (ความถี่สูง/กลาง)" v2 ทำด้วย Chebyshev filter bank $K$ ชั้น anchored solve ให้ response เดียว $1/(1+\tau\lambda)$ (low-pass) คำถาม: เสียอะไร

วิเคราะห์ พิสูจน์

ให้ $S$ คือ operator ระดับโหนดหลังกำจัด $s,z$ (PSD) แล้ว $x^\star=(I+\tau S)^{-1}h$ หัวทำนายอ่าน $[h,x^\star]$ ดังนั้นชั้น linear แรกของหัวทำนายคำนวณได้ทุก $Ah+Bx^\star$ โดยเฉพาะ

$$h-x^\star=(I+\tau S)^{-1}\big((I+\tau S)-I\big)h=\tau S(I+\tau S)^{-1}h\quad\Rightarrow\quad\text{response }\frac{\tau\lambda}{1+\tau\lambda}\ \text{(high-pass)}$$

ดังนั้น low-pass และ high-pass ต่อพิกัด มีอยู่แล้ว ที่หัวทำนายโดยไม่ต้องมี filter bank และต่อพิกัดจริงเพราะ $A,B$ เป็นเมทริกซ์ $d\times d$ สิ่งที่หายคือ band-pass (เก็บเฉพาะ λ ช่วงกลาง) ซึ่งต้องการ τ สองค่า: $(I+\tau_1S)^{-1}-(I+\tau_2S)^{-1}$

ทำไม band-pass ไม่จำเป็นต้องมีในรุ่นนี้ เหตุผล

  • R9 อ้าง PolyNSD §3 ว่า first-order update "$(I-\eta A)^K$ damps high frequencies" ข้อนี้จริงสำหรับการแพร่ทีละก้าวที่หัวทำนายอ่านแค่ $x$ แต่ไม่จริงเมื่อหัวทำนายอ่าน $[h,x^\star]$ (R11 ego/neighbour separation ที่ v2 มีอยู่แล้ว) การอ้างนี้จึงใช้ไม่ได้กับโมเดลเรา
  • ไม่มีบทพิสูจน์หรือหลักฐานใน spec ว่า heterophily ต้องการช่วงกลางโดยเฉพาะ ทฤษฎีบท 4 แสดงว่าการแยก class ภายใต้ heterophily ทำได้ที่ λ = 0 (global section) ผ่าน map ไม่ใช่ผ่านความถี่
  • filter bank มี $K$ เป็น hyperparameter (OPEN-4 ยังเปิดอยู่ตั้งแต่ v1.2) และ $W_0..W_K$ อีก $(K+1)d^2$ พารามิเตอร์ ตรงกับสิ่งที่คุณขอให้หลีกเลี่ยง

6. D-B3 normalization

ปัญหา

energy ไม่ normalize: โหนดที่มี fact มาก (hub: subject ใน ACM, หนังสือใน Freebase ที่มี 5,548 fact) มี $D_v=\sum_ea_e$ ใหญ่มาก คำถามสองข้อ: (1) hub ถูกดึงไปที่ค่าเฉลี่ยของเพื่อนบ้านแรงเกินไปไหม (ความกังวลจริงของ R4 เดิม) (2) จำนวนรอบ PCG ขึ้นกับอะไร (scalability ที่ R1, R3, R4, meta ถามทั้งหมด)

วิเคราะห์ พิสูจน์

หลังกำจัด $s,z$ ทั้งหมด ระบบระดับโหนดคือ $(I+\tau S)x^\star=h$ โดย $S$ คือ Schur complement ของ $L$ ต่อโหนด สมบัติมาตรฐานของเมทริกซ์ PSD แบบ block $\begin{bmatrix}A&B\\B^\top&C\end{bmatrix}$: $0\preceq A-BC^{-1}B^\top\preceq A$ ดังนั้น $0\preceq S\preceq L_{xx}$ และ $L_{xx}=\mathrm{diag}(D_vI)$ เพราะ $F^\top F=I$ (block แนวทแยงของ $L$ ที่โหนดคือ $\sum_ea_eF^\top F+\sum_f\beta_fT^\top T=D_vI$)

  • ไม่ normalize: eigenvalue ของ $I+\tau S$ อยู่ใน $[1,\,1+\tau\max_vD_v]$ ⇒ cond ≤ $1+\tau\max_vD_v$ ขึ้นกับ hub และสำหรับ hub เอง $x^\star_v$ ถูกดึงเข้าหาค่าเฉลี่ยเพื่อนบ้านด้วยน้ำหนัก $\tau D_v$ เทียบกับ 1 ของ anchor ⇒ hub สูญเสีย $h_v$ แทบหมด นี่คือสิ่งที่ R4 ห่วง
  • normalize แบบสมมาตร $\hat L=D^{-1/2}LD^{-1/2}$ กับ $D=\mathrm{diag}(D_v,D_e,D_f)$ (ทุกระดับ): block โหนดของ $\hat L$ เป็น $I$ พอดี ⇒ $0\preceq\hat S\preceq I$ ⇒ eigenvalue ของ $I+\tau\hat S$ อยู่ใน $[1,1+\tau]$, cond ≤ $1+\tau$ ไม่ขึ้นกับขนาดกราฟและไม่ขึ้นกับ hub และ $\|x^\star-h\|\le\tfrac{\tau}{1+\tau}\|h\|$ ในนอร์มรวมทั้งกราฟ (ไม่ใช่ขอบเขตต่อโหนด: ผลต่อ hub รายตัวยังไม่ได้พิสูจน์ ต้องวิเคราะห์หลังรัน)

ขอบเขตนี้พิสูจน์สำหรับระบบระดับโหนดหลังกำจัด สำหรับระบบเต็ม $M=P^\top P+\tau\hat L$ ที่ PCG แก้จริง ผมยังไม่มีขอบเขต (Jacobi preconditioner บน toy ให้ cond 27.5 ไม่ normalize) ต้องวัดบน operator จำลองขนาด ACM แต่เป็นงานบน CPU ไม่ใช่ dataset run

7. D-B4 τ

ปัญหา

v3B_design เสนอ τ = 1 คงที่ด้วยเหตุผลว่า "สเกลของ $a_e,\beta_f$ เรียนรู้ได้อยู่แล้ว" เหตุผลนี้ ใช้ไม่ได้หลัง D-B3: ถ้าคูณ $a_e,\beta_f$ ทุกตัวด้วย $c>0$ ทั้ง $L$ และ $D$ ถูกคูณ $c$ จึง $\hat L$ ไม่เปลี่ยน สเกลรวมถูกตัดทิ้ง τ กลายเป็นปุ่มสเกลเดียวที่เหลือ และคำตอบขึ้นกับมันจริง: response $1/(1+\tau\lambda)$ บน $\lambda\in[0,2]$ ที่ τ = 1 ความถี่สูงสุดถูกลดเหลือ 1/3 เท่านั้น

ข้อสังเกตที่ควรใส่ใน paper พิสูจน์

$(I+\tau\hat S)^{-1}$ คือ personalized PageRank บน sheaf: APPNP (Klicpera et al. 2019) ใช้ $\alpha(I-(1-\alpha)\hat A)^{-1}$ กับ $\hat A=I-\hat L_{\text{graph}}$ ซึ่งเท่ากับ $(I+\tfrac{1-\alpha}{\alpha}\hat L)^{-1}$ ดังนั้น $\tau=(1-\alpha)/\alpha$ และ τ = 1 คือ α = 0.5 (APPNP ใช้ α ≈ 0.1 คือ τ ≈ 9) การวางตำแหน่งนี้ซื่อและมีประโยชน์: การแพร่ระดับโหนดของเราคือ PPR บน sheaf สามระดับที่กำจัดแล้ว สิ่งที่เป็นของเราคือ $\hat S$ ไม่ใช่รูปของ solve

ทางเลือก

ทางข้อดีข้อเสีย

9. ทฤษฎีบท 7′: กำจัด fact ที่อยู่บน cell เดียวโดยไม่เปลี่ยนคำตอบ พิสูจน์ ตรวจ numpy 7e-16

ขยายทฤษฎีบท 7 (fact บนศูนย์ cell) ไปยัง fact บน cell เดียว: ใช้สูตรในข้อ 1 ตรง ๆ ผลคือเทอมตรงน้ำหนัก $a_e^2/(2a_e+\beta_f)$ และเทอมโหนด–cell น้ำหนัก $a_e\beta_f/(2a_e+\beta_f)$ ที่ปลายทั้งสอง (ซึ่งใน D-B0(b) รวมกับเทอมโหนด–cell ที่มีอยู่แล้วเป็น $\beta_f+\frac{a_e\beta_f}{2a_e+\beta_f}$) เพราะ $s_e$ ไม่ปรากฏในเทอมอื่น การกำจัดจึงไม่เปลี่ยน $x^\star$ และ $z^\star$ (คำตอบของปัญหาเดิมฉายลงตัวแปรที่เหลือ) ผล: state บนเส้นต้องเก็บเฉพาะ $E_{\text{shared}}$ และตำแหน่งที่ (ค) ในข้อ 1 ทำงานก็คือตรงนี้พอดี — โค้ดจึงเก็บ state ตรงที่มันมีความหมายเท่านั้น

ข้อควรระวัง: การกำจัดทำก่อน normalization (D-B3) หรือหลัง? เพื่อให้ $\hat L$ นิยามเดียว ให้ normalization ทำบน $L$ เต็ม (รวม $s_e$ ทุกตัวในนิยาม $D_e$) แล้วกำจัด — ผลลัพธ์เท่ากันเพราะการกำจัดเป็นการแก้ปัญหาเดียวกันบางส่วน ส่วน $D_v$ ไม่เปลี่ยน

10. D-B6 และ D-B7

D-B6 householder_k = 2

v3B_design §15 เขียนว่า "ทฤษฎีบท 4 อาจต้องการการสะท้อนถึง d ครั้ง (Cartan–Dieudonné)" ข้อนี้ผิด: บทพิสูจน์ทฤษฎีบท 4 สร้าง map จาก $F_{u\triangleleft e}=I$ และ $F_{v\triangleleft e}=H(a_{y(v)}\to a_{y(u)})$ คือการสะท้อน หนึ่งครั้ง ต่อ incidence (frame $R=I$) k = 1 ก็เพียงพอ Cartan–Dieudonné เกี่ยวกับการแทน rotation ที่กำหนดให้ ใด ๆ ซึ่งทฤษฎีบท 4 ไม่ต้องการ ข้อเสนอ: คง k = 2, ลบข้อจำกัด, เขียนแทนว่า "ทฤษฎีบท 4 ต้องการ k ≥ 1 และ frame ที่เป็น I ได้" (frame เรียนรู้ได้จึงเป็นจริง) สิ่งที่ k = 2 จำกัดจริงคือ ชุดของ map ที่โมเดลพูดได้ (ไม่ครอบคลุม O(d) ทั้งหมด) ซึ่งเป็น L4 ที่มีอยู่แล้ว

D-B7 ค่าเริ่มของ PCG

$Y_0=P^\top h$ ($s,z$ = 0) ไม่กระทบคำตอบ (ระบบ SPD มีคำตอบเดียว) กระทบแค่จำนวนรอบ ทางเลือก "เริ่มจาก $s_e=\tfrac12(F_uh_u+F_vh_v)$, $z_f$ = ค่าเฉลี่ย" คือค่าดีที่สุดของ $s,z$ เมื่อ $x=h$ จึงเริ่มใกล้กว่าแน่ และคำนวณได้ด้วย UP ครั้งเดียว ข้อเสนอ: ใช้ค่าหลังนี้ (ฟรี ไม่มีพารามิเตอร์) ต่างจาก v3B_design เล็กน้อย
