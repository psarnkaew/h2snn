## Goal and rule
H2S-NN can train and evaluate in mini-batch on the eight H2GB node-classification datasets and the two large link-prediction tasks, each target predicted by the same model on its own scope (Lemma R), while every full-batch path stays **bit-identical**. **Correctness only:** unit tests, oracle tests on tiny synthetic graphs, mutation checks, the full suite once. No smoke run on real data, no performance experiment, no metric reported as a result, no comparison between methods. The H2GB data and loaders are not available (Part M M3 card, lab cluster): every test uses synthetic graphs. **Out of scope (N1):** baseline adapters' batch size and epoch on H2GB datasets (M3 card); the heterophily harness (M2); HetSheaf (cluster card).

### MB1 — Scope builder and global node ids
New `src/data/scopes.py`: from a graph (any `PreparedH2SData`-like graph, N6), a list of targets and each target's cells, build one batch = the **disjoint union** of the targets' scopes, with: the batch's `PreparedH2SData`; `global_node_id` (batch row → node id in the given graph); the scope id of every node, fact and cell; the row of each scope's target. Scope of target `t` (`minibatch_design_v3B.md` §3): `t`; every fact of `t` (self-loop facts included) and its other endpoint; every node and fact of `t`'s cells. **Nothing else** (no induced facts between scope nodes). A node in several scopes is copied into each. Featureless types read the embedding row of the **global** id: add an optional `global_node_id` to `PreparedH2SData` (None → the current behaviour, exactly).
**Tests:** on the §2 example graph (P1 with authors, fields, citations; hand cells) the scope's nodes, facts and cells equal the hand lists; lower set (every cell's facts and nodes, every fact's endpoints are in the scope); no fact between two scope nodes unless it is a fact of `t` or on a cell of `t`; functoriality of the forced cell maps on scope cells (existing check); a featureless node in two scopes gets the same `h₀` as in the whole graph; a scope built on a second synthetic graph uses that graph's facts only. **Mutations:** local position instead of global id → the `h₀` test fails; one induced fact added → the lower-set/no-induced test fails.

### MB2 — Chunked draw and per-anchor merge
In mini-batch draws only, `sample_wisp_walks` runs in chunks of 4,096 anchors, each with its own generator seeded from (seed, chunk index) by one stated formula; full-batch draws are unchanged. Cells are merged **per anchor** (the anchor in the merge key; `m_f` summed over that anchor's walks only).
**Tests:** same seed and chunk size → identical draw (`torch.equal`); every walk's `log p` equals the unchunked rule's `log p` for the same walk, and on a small graph the walk frequencies from one anchor match exact enumeration (≥ 1e5 walks, 4σ); two chunks never reuse a generator state (distinct seeds; a planted anchor in chunk 2 does not copy chunk 1's walk); the same instance drawn from two anchors gives two cells, each with its own `m_f`; **full-batch bit-identity**: the MB0 reference draws and `test_task_heads` golden outputs are unchanged. **Mutations:** anchor dropped from the merge key → the per-anchor test fails; the chunk seed ignores the chunk index → the distinct-chunk test fails.

### MB3 — The model on a batch of scopes
The model runs unchanged on the batch graph (context `c`, degrees, normalisation, `E_shared` and elimination are then per scope because no fact crosses scopes; verify, do not assume). It passes the scope id of **every row of the solved system** (nodes, kept fact states, cells) to `anchored_solve` as `scope_rows`, with per-scope stopping and per-scope `T_max`. The evaluation warm start is off in mini-batch, and in full batch it is used only when the evaluation draw is the same one (not only the same shape). The log-weight range is checked per forward (= per batch).
**Tests (float64 unless stated):** (a) **batch = scopes alone**: solver tolerance 1e-10, `x*` of every target from a batch of ≥ 4 scopes of different sizes equals the scope solved alone, max relative difference ≤ 1e-8; (b) production setting (float32, tol 1e-4): every scope's own relative residual ≤ 1e-4; (c) **independent of batching**: evaluation logits with batch sizes 3 and 7 and a shuffled order agree within 1e-8 relative (tol 1e-10); (d) **whole-graph harness**: one scope made of every fact and every anchor's walks merged as in full batch reproduces the full-batch logits within 1e-8 (plumbing check); (e) context and degrees of a scope node equal those computed on the scope alone; (f) no warm start in mini-batch evaluation (the initial guess is the D-B7 one; spy on `y0`). **Mutations:** one global inner product (`scope_rows` None) on scopes of very different scale → (b) fails; warm start re-enabled in mini-batch → (f) fails.

### MB4 — Mini-batch trainer for node classification
Training mode resolved per dataset (table above); the analysis flag; the tuner allows `batch_size` only on the H2GB NC datasets and refuses the flag and the epoch field. One epoch = `epoch_targets / B` steps over the continuing seeded permutation; one optimizer step per batch; loss mean over the batch; training draw per batch; tolerance schedule by epoch. Evaluation every `eval_period` epochs of the source protocol (H2GB 4; OAG 2) on the whole validation and test splits in batches of 1,024 with the fixed evaluation draw; budget as spec §6 (H2GB: 500 epochs, no early stopping, checkpoint at the best validation evaluation). Inductive evaluation: the evaluation scopes are built on the evaluation graph passed in (N6).
**Tests:** steps per epoch = `epoch_targets / B` for `B` ∈ {32, 256, 1024} (synthetic graph; `epoch_targets` set explicitly in the test); over consecutive epochs every training target is visited once per pass, the order is deterministic per seed and differs per pass; training draw seeds differ per (epoch, batch); the evaluated set equals the whole split (count and ids) and the metric equals the metric on the concatenated predictions; evaluation predictions do not depend on the evaluation batch size (float64, as MB3 c); a stop condition in one batch stops the run with its named exception; the tuner refuses `batch_size` on ACM, the flag, and the epoch field; an evaluation graph different from the training graph is used for its scopes (two synthetic graphs). **Mutations:** epoch = fixed number of steps regardless of `B` → the steps test fails; evaluation on a random subset → the whole-split test fails.

### MB5 — Large link prediction (MB4 of the design, spec §6)
For ogbn-mag P–P and H-Pokec U–U (registered names; data pending): each endpoint of a step's positive and negative links is a target with its own scope (anchors = those endpoints only); a node appearing in several links of the step is computed once; the decoder scores `(x*_u, x*_v)` as in full batch; 8,192 positives per step, BCE with 1:1 training negatives, 40 epochs, patience 40; evaluation computes the scopes of all validation/test endpoints once and scores every link; held-out facts are removed in both orientations before any draw.
**Tests (synthetic same-type graph):** link scores equal those from each endpoint's scope solved alone (float64, ≤ 1e-8); a repeated endpoint is solved once (spy) and gets one `x*`; no held-out fact (either orientation) is in any scope; evaluation scores every validation/test link. **Mutation:** a held-out fact kept in the message graph → the leak test fails.

## Rules and stop conditions
- One commit per unit, explicit paths, tests with the change. Never stage line-ending-only diffs, `Claude outputs/`, `data/`, `H2S-NN/paper/`, vendor clones. Forbidden: loosening tolerances, deleting or skipping tests, silencing exceptions, special-casing inputs, editing the spec or the card.
- **Tests must not reach real data:** a test that points at a fixture also makes the real data root unreachable at import time (Part P-fix finding: a module-level bound root read the real Freebase files).
- **Stop:** any full-batch output changes (MB2/MB3 bit-identity) → stop the unit, report the first differing tensor; MB3 (a) misses 1e-8 at tol 1e-10 → stop, report the first differing scope and its size (do not relax); a change would alter the method (energy, maps, `g`, solver, WISP's `p`) → stop the unit; a requirement needs H2GB data → report and continue with synthetic tests only.
- **Not stop conditions:** any metric value; PCG iteration counts.
