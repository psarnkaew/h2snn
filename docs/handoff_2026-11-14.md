## 4. Discussions closed this session (no change to the method)
- H2GB's own code and paper use no meta-path for message passing on any dataset: only ℋ² (all length-2 target→target type sequences) and MetaPath2Vec positional encoding (fixed lists; on in H2G-former configs of ogbn-mag, mag-year, oag-chem, PDNS, Pokec). H2GB's HAN = `HANConv` on raw relations. Recorded in `predefined_metapaths.md`.
- WISP weight `g`: already sees types (type embedding inside `h₀`) and the relation-with-direction sequence (the finer schema). Author asked whether to split type / relation / instance: answer — a type term is redundant with relations; a separate schema+instance weight adds no capacity, only interpretability, and moves toward HAN; not adopted. Offered (declined for now): a read-out decomposing `Var(log w_f)` into between-schema and within-schema parts as evidence for storyline (ii).
