# Task card — Part P: baselines runnable on every local cell (HetSheaf adapter, derived LP tasks, Freebase NC)

**Design authority:** spec **v1.20** (§6 Ablation table: the fixed-literature-schema row; §6 Baselines, Node classification, Link prediction, Graph classification, Tuning) and `docs/experiment_settings_decisions.md`. `H2S-NN/AGENTS.md`/`CLAUDE.md` bind for environment (conda env `h2snn`), coding, testing (`unittest`) and evidence tags. `src/baselines/protocol.py` (module docstring) is the adapter contract.
**Branch:** `part-p`, created from `part-o` at the commit given in the prompt (it contains Part O O0–O4 and the design docs of 2026-11-13). **Precondition:** the author has read `docs/H2S-NN_partO_report.md`; his decisions on it are in `docs/experiment_settings_decisions.md` (rows "Part O review"). **Report:** `docs/H2S-NN_partP_report.md`; evidence `docs/partP_evidence/`.

## Goal and rule
Every **local** cell of the main tables becomes runnable: (1) HetSheaf as a baseline on NC, LP and GC; (2) the four derived LP tasks (acm_pa, dblp_ap, imdb_ma, freebase_bb) for every LP baseline; (3) Freebase NC for H2S-NN and every NC baseline. **Correctness only** (author, 2026-11-12/13): unit tests, tests that run an adapter's `fit_task` for one epoch on a tiny synthetic release in the real file format, mutation checks, the full suite. **No smoke run on real data, no performance experiment, no metric reported as a result, no comparison between methods.** H2GB datasets stay "data pending" (mini-batch card). WISP and the method are not touched.

## Scope rules
- One commit per unit; stage by explicit path; never stage line-ending-only adapter diffs (the working tree's `src/baselines/adapters/*` diffs are line endings only, `git diff --ignore-cr-at-eol` empty, 2026-11-13; a unit that edits one of these files stages only its own content change), `Claude outputs/`, `data/`, vendor clones (except a `CLONED_COMMIT.txt` convention file), or other sessions' files.
- Each baseline keeps its own preprocessing as its original code does (spec v1.14 H9); data files, splits and negatives are shared (spec v1.16–1.18). Shared protocol (AdamW, shared lr/wd/dropout axes, no scheduler, no clipping, budgets per source, failed-trial rule) applies to every adapter (spec v1.15 J4, v1.16 K5).
- Forbidden: loosening tolerances, deleting or skipping tests, silencing exceptions, special-casing inputs, editing the spec to fit the code. Out-of-scope problems are listed, not fixed.

## Units

### P0b — Part O follow-up: the fixed-literature-schema row (spec v1.20 U-1; decisions D-O3, D-O4, D-O6)
This is H2S-NN's comparison row only (`is_literature_row`); no baseline, no WISP main-model code path and no legacy schema row (`r` unset, e.g. the bundles' pinned DFS row) changes. Files: `src/data/literature_paths.py`, `src/configs/config.py` (builder), the row's tests.
1. **Hop rule (D-O3).** Within a listed meta-path each hop follows WISP's rule with the action fixed by the list: a uniform fact of the listed (relation, direction) from the current node to an **unvisited** node; a dead end discards the walk. Reuse WISP's own step (`wisp_sampler.sample_wisp_walks`, docstring l.8, and its unvisited-fact counting) with the action forced, or an equal-output helper; D8's `sample_walks` (rejection of revisits) is no longer used by the row.
2. **Cell mass (D-O4).** A walk of listed path π carries `m = 1/(k·r_π)` (k listed paths of the dataset, `r_π` its walks per anchor from `literature_walk_split`); merged per cell as now (`merge_length_group`, sum).
3. **Run directory (D-O6).** `fixed_literature_schema_config` also sets its own run name (`<exp_name>__literature_row`); the diff test allows exactly `data.path_source` and the run name; `output_dir` unchanged.
**Tests:** (a) hop rule: on a hand graph (anchor P1, author A7 with papers P1, P2, P3) the exact probability of each P1–A7–P_j instance equals WISP's (1/2 each), against the hand value and against `sample_wisp_walks` on the same graph with a one-action graph, by exact enumeration where possible and Monte Carlo (≥ 1e5 walks, 4-sigma bound) otherwise; a dead end discards; (b) mass: per anchor and listed path the expected sum of `m` over its walks equals `(1/k)·P(walk not discarded)`, and on a graph without dead ends the total per anchor is 1 (exact, float64); (c) row vs `full` on the same graph: total cell mass per anchor of both ≤ 1 and equal when neither has dead ends; (d) run directory of the row ≠ that of the `full` configuration it was built from, and building a row from a row is refused (as now); (e) all Part O row tests still pass (update only those that assert the old `1/r_π` or D8 walk, each named in the report). **Mutation:** `m = 1/r_π` → test (b) fails; D8 rejection walk → test (a) fails.

### P1 — HetSheaf adapter (NC, LP, GC)
New `src/baselines/adapters/hetsheaf.py` (+ helpers as needed), importing HetSheaf's model classes from the vendor clone (no copy of their code into `src/`), registered in `registry.py` (replaces `ADAPTER_PENDING["hetsheaf"]`), `runtime/vendor_paths.py`, `runtime/dependencies.py`.
- **Variants:** implement every variant P0(a) lists as a parameter `variant` of the one adapter. **Default campaign row (author may change after the report; recorded under decisions):** one registry row per variant the paper's main tables report.
- **Inputs:** the canonical bundle (shared files/splits/negatives) turned into HetSheaf's homogeneous graph with node-type and edge-type attributes exactly as `datasets/hgb.py` builds it, **including HetSheaf's transforms of P0(d)** (they are part of the method, spec H9). State any transform that cannot apply to a shared split (e.g. one that would add a held-out LP edge) and do not apply that one; list it.
- **NC:** HetSheaf's own model and head (protocol: NC runs the authors' head); multi-label IMDB through the project's IMDB rule (BCE per genre, logit > 0) as every adapter does.
- **LP:** HetSheaf's encoder + the shared LP head (`src/baselines/heads.py`), shared training/validation/test negatives (HGB's functions), both test sets (2-hop, random).
- **GC:** HetSheaf's encoder; readout per decision **D-P2** below (default: HetSheaf's own readout options incl. `late_token`).
- **Search space:** each variant's sweep space from P0(b), with the shared axes (lr, weight decay, dropout ranges of `search_grids.py`) replacing theirs where they overlap; their published values must be reachable (`SearchSpaceCoverageTests` pattern).
- **Shared protocol:** AdamW, no scheduler (their `configure_optimizers` builds a cosine scheduler: not used), no clipping, budgets per task/source, failed-trial rule.
**Tests:** a tiny HGB-format NC release, a tiny derived-format LP release, a tiny TU-like GC set: `fit_task` runs one epoch per variant per task and returns a record with the task's keys (values not asserted beyond finiteness); the homogeneous graph's node/edge type attributes equal a hand construction; each transform of P0(d) is applied (and the excluded one is not); AdamW, no scheduler; search space contains the published values. **Mutation:** drop the edge-type attribute → a test fails.

### P1b — H2G-former's encoder as H2GB's (spec v1.19 T2)
`src/baselines/adapters/h2gformer.py` (and `_h2gformer_lp.py`): replace the fixed `Hetero_Raw` encoder by spec v1.19 T2, using H2GB's own encoder classes (`H2GB/encoder/hetero_label_encoder.py`, `hetero_pos_encoder.py`) and, for `Hetero_Metapath`, H2GB's MetaPath2Vec code path (`preprocess_Metapath`/`load_Metapath` for H2GB datasets; for HGB datasets the same MetaPath2Vec call with the walk schema of T2 and H2GB's settings). New search-space key `metapath_pe` ∈ {on, off} for cells without an H2GB config; H2GB cells take their config's stack (no key). The concatenated walk schemas per dataset are written in one table in the adapter (from `docs/predefined_metapaths.md`, HGB's table order) and in the report. H2GB datasets stay "data pending": wire their path, test on a tiny HeteroData.
**Tests:** the encoder stack resolved per (dataset, task, `metapath_pe`) equals T2; each concatenated schema is cyclic (starts and ends at the same type), every hop is an edge type of the dataset's graph, and it equals the concatenation of the listed meta-paths in table order; MetaPath2Vec settings equal H2GB's; **information-route test:** poisoning validation/test labels leaves the label channel's input unchanged; MetaPath2Vec embeddings are produced and consumed on a tiny graph. **Mutation:** feed all labels to the label channel → the route test fails; drop one listed meta-path from a schema → the schema test fails.

## Stop conditions
- P0 finds that HetSheaf's code cannot run in `h2snn` (dependency conflict): stop P1, report the conflict; P2–P3 continue.
- A transform or protocol point cannot be followed without changing shared data/splits/negatives: do not change them; report.
- A change would alter H2S-NN's method or needs an open decision: stop the unit, report.
**Not stop conditions:** any metric value in a test (only finiteness and keys are asserted).
