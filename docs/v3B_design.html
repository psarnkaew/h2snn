H2S-NN v3-B: 2-cell ที่ส่งผลเข้าโหนดผ่านเส้นจริง

เอกสารนี้นิยามโมเดล v3-B ให้ครบพอสำหรับเขียนโค้ด ทุกสมการมาพร้อมคำอธิบายในภาษาง่ายและตัวอย่าง P1–A7–P9 บทพิสูจน์ฉบับเต็มอยู่ใน docs/v3_A_vs_B.html ข้อ 9 (เรขาคณิต) และไฟล์ของ ChatGPT ข้อ 20 (การลู่เข้า) เอกสารนี้สรุปผลและระบุที่มาของแต่ละข้อ

1. สิ่งที่ตัดสินแล้ว (ผู้เขียน 10 พ.ย. 2026)

  1. ใช้ B เป็นโมเดลหลัก: state อยู่ที่ 3 ระดับ (โหนด, เส้นจริง, 2-cell) ข้อมูลระหว่างโหนดกับ cell วิ่งผ่านเส้นจริงของ path เท่านั้น
  2. closure edge อยู่ในนิยามของ complex เท่านั้น: ทำให้ path เป็น 2-cell จริงและใช้ในบทพิสูจน์ แต่ไม่มี state และไม่อยู่ใน energy ไม่มีทางลัดปลาย-ปลาย
  3. ไม่ใช้ C: ไม่มีเทอมโหนด–cell ตรง เพราะข้อติ R2 W3 อยู่ที่ "ทางเข้าโหนดผ่าน closure" ส่วน face ทำงานบนเส้นเป็นสิ่งที่ R2 ชม
  4. การแพร่ใช้ตัวแก้ที่ยึด encoding: ปัญหา quadratic เดียว (ข้อ 8) ตามข้อ 20 ของไฟล์ ChatGPT
  5. ไม่ใช้ Hodge Laplacian ของ complex เป็นตัวแพร่: เพราะ Lemma A′ ทำให้ face ส่งข้อมูลถึงโหนดไม่ได้ และห้ามใช้ชื่อ "Sheaf-Hodge diffusion"
  6. ตัวควบคุมใช้ anchor และ readout เดียวกัน: ได้แก่ A (v2 hub), แขน closure-only และแขนที่ไม่มี cell (ข้อ 11)
  7. ส่วนที่คงจาก v2: WISP, map แบบแยกตัวประกอบที่คำนวณครั้งเดียว, การแปลงพิกัดแบบไม่สร้างเมทริกซ์, fact layer (D7), local-scope mini-batch (M0–M4), การแก้ข้อมูลและ protocol ทั้งหมด (Part J)

4. ข้อมูลเข้า

  1. กราฟ: ชนิดโหนด $\phi(v)$, feature ตามชนิด (ชนิดที่ไม่มี feature ใช้ embedding ตาม global id, mini-batch doc §11), เส้นจริงตาม D7 พร้อมชนิดและบทบาท (ต้น/ปลาย)
  2. WISP draw: เก็บต่อ walk ว่า (anchor, ลำดับโหนด, ลำดับเส้น, น้ำหนัก IS) แล้วรวม walk ที่ได้ path เดียวกันเป็น cell เดียว:
    $$m_f = \sum_{\omega\to f}\frac{1}{r}\cdot\frac{p(\omega)}{\tfrac12p(\omega)+\tfrac12q(\omega)}$$
    ตอนเทรนสุ่มใหม่ทุก epoch ตอนประเมินใช้ draw คงที่ (E1) walk เป็น simple path (โค้ดใช้ unvisited)
  3. ตารางที่สร้างครั้งเดียวต่อ draw:
    • $E_P$ และตำแหน่งของแต่ละเส้นใน state $s$
    • รายการ incidence ของ cell คือ (f, i, e_i, v_{i−1}, v_i)
    • รายการ incidence โหนด–เส้นของ $E_P$
    • รายการเส้นใน $E_0$ (ใช้เทอมตรง ข้อ 7.2)

ตัวอย่าง: เส้น e0 = (P1, A7), e1 = (A7, P9), e2 = (A7, P4), e3 = (P1, S3) ได้ cell f1 = P1–A7–P9 และ f2 = P1–A7–P4 ดังนั้น $E_P = \{e_0,e_1,e_2\}$ และ $E_0 = \{e_3\}$

6. เรขาคณิต: map และ transport

6.1 transport ตาม cell (ไม่สนทิศที่เก็บของเส้น)

$$T_{v_0,f} = I,\qquad Q_i = F_{v_{i-1}\triangleleft e_i}^{\top}F_{v_i\triangleleft e_i},\qquad T_{v_i,f} = T_{v_{i-1},f}\,Q_i$$
$$R_{e_i,f} := F_{e_i\triangleleft f} = T_{v_{i-1},f}\,F_{v_{i-1}\triangleleft e_i}^{\top}$$

$R_{e_i,f}$ แปลง state ของเส้น $e_i$ ไปเป็นภาษาของ cell ทุกตัวเป็นการหมุนหรือสะท้อน เพราะ F เป็นแบบนั้น ถ้า walk เดินย้อนทิศที่เก็บของเส้น สูตรนี้ใช้ได้เหมือนเดิม เพราะใช้ map ของ "โหนดที่เดินออก" กับ "โหนดที่เดินเข้า" และ energy ไม่มีเครื่องหมาย จึงไม่ต้องมี η

ตัวอย่าง f1:

$$R_{e_0,f_1} = F_{P1\triangleleft e_0}^{\top},\qquad T_{A7} = F_{P1\triangleleft e_0}^{\top}F_{A7\triangleleft e_0},\qquad R_{e_1,f_1} = T_{A7}F_{A7\triangleleft e_1}^{\top}$$

6.2 คำนวณแบบไม่สร้างเมทริกซ์

ทุกครั้งที่ต้องใช้ ให้คูณ map เข้ากับ vector ตามลำดับ ต้นทุนเท่ากับการใช้ map ประมาณ ℓ ครั้งต่อ cell

UP (เส้น → cell):  m_f = Σ_i R_{e_i,f} s_{e_i}
  u ← 0
  for i = ℓ … 1:                       # Horner, from the end of the path
      u ← Q_i u + F_{v_{i-1}◁e_i}ᵀ s_{e_i}       # Q_i u = F_{v_{i-1}◁e_i}ᵀ (F_{v_i◁e_i} u)
  m_f = u                              # T_{v_0} = I

DOWN (cell → เส้น):  r_{e_i} += R_{e_i,f}ᵀ z_f = F_{v_{i-1}◁e_i} T_{v_{i-1}}ᵀ z_f
  t ← z_f                              # T_{v_0}ᵀ z_f
  for i = 1 … ℓ:
      r_{e_i} += F_{v_{i-1}◁e_i} t
      t ← Q_iᵀ t                       # T_{v_i}ᵀ z_f

v2 มี PathTransportOperator (map_operators.py:413) ซึ่งทำ $T_v x_v$ ตาม path อยู่แล้ว ต้องเพิ่มเวอร์ชันที่รับ state ของเส้นแทน state ของโหนด

6.3 closure

closure $c_f$ มี map ในนิยามคือ $F_{v_0\triangleleft c_f} = I$, $F_{v_\ell\triangleleft c_f} = T_{v_\ell,f}$, $F_{c_f\triangleleft f} = I$ ใช้ในบทพิสูจน์ (ทฤษฎีบท 1–2) ไม่มีในโค้ด ไม่มี state ไม่มี incidence และไม่มีเทอมใน energy (ทฤษฎีบท 1b)

7. energy และ operator

7.1 energy ของการแพร่

$$E(Y) = \underbrace{\frac12\sum_{e\in E_P}a_e\sum_{v\in e}\big\lVert F_{v\triangleleft e}x_v - s_e\big\rVert^2}_{\text{โหนด–เส้น (เส้นบน cell)}} + \underbrace{\frac14\sum_{e=(u,v)\in E_0}a_e\big\lVert F_{u\triangleleft e}x_u - F_{v\triangleleft e}x_v\big\rVert^2}_{\text{เส้นที่ไม่อยู่บน cell}} + \underbrace{\frac12\sum_{f}\beta_f\sum_{i=1}^{\ell_f}\big\lVert R_{e_i,f}\,s_{e_i} - z_f\big\rVert^2}_{\text{เส้น–cell}}$$
  • เทอมแรก: state ของเส้นควรตรงกับทั้งสองปลายหลังแปลง
  • เทอมที่สอง: คือเทอมแรกหลังแก้ค่า $s_e$ ทันที (ได้ $\tfrac12 a_e\cdot\tfrac12\lVert\cdot\rVert^2$, ทฤษฎีบท 7) จึงไม่ต้องเก็บ state ของเส้นที่ไม่มี cell ผ่าน
  • เทอมที่สาม: state ของ cell ควรตรงกับเส้นทุกเส้นบน path หลังแปลง

ตัวอย่าง: พจน์ของ f1 คือ $\tfrac{\beta_{f_1}}{2}\big(\lVert F_{P1\triangleleft e_0}^{\top}s_{e_0} - z_{f_1}\rVert^2 + \lVert T_{A7}F_{A7\triangleleft e_1}^{\top}s_{e_1} - z_{f_1}\rVert^2\big)$ ส่วน $e_3$ (P1–S3) ใช้เทอมที่สอง

7.2 operator $L = \nabla^2E$ (สมมาตร, ไม่ติดลบ)

ผลของ $L$ ต่อ $Y$ คำนวณจาก incidence โดยไม่สร้างเมทริกซ์

$$(LY)_v = \sum_{e\in E_P,\,e\ni v}a_e\,F_{v\triangleleft e}^{\top}\big(F_{v\triangleleft e}x_v - s_e\big) + \sum_{e\in E_0,\,e\ni v}\tfrac{a_e}{2}\,F_{v\triangleleft e}^{\top}\big(F_{v\triangleleft e}x_v - F_{u\triangleleft e}x_u\big)$$
$$(LY)_e = \sum_{v\in e}a_e\big(s_e - F_{v\triangleleft e}x_v\big) + \sum_{f\ni e}\beta_f\,R_{e,f}^{\top}\big(R_{e,f}s_e - z_f\big)$$
$$(LY)_f = \beta_f\sum_{i}\big(z_f - R_{e_i,f}s_{e_i}\big)$$

ใช้ $F^{\top}F = I$ และ $R^{\top}R = I$ ได้ค่าบนแนวทแยงเป็นสเกลาร์คูณ I:

$$D_v = \sum_{e\in E_P\ni v}a_e + \sum_{e\in E_0\ni v}\tfrac{a_e}{2},\qquad D_e = 2a_e + \sum_{f\ni e}\beta_f,\qquad D_f = \beta_f\,\ell_f$$

ใช้เป็น preconditioner (ข้อ 8)

8. การแก้ปัญหา

8.1 ปัญหาเดียวที่ยึด encoding

$$Y^{\star} = \arg\min_Y\ \tfrac12\lVert x - h\rVert^2 + \tfrac{\tau}{2}\,Y^{\top}LY \quad\Longleftrightarrow\quad M\,Y^{\star} = P^{\top}h,\qquad M = P^{\top}P + \tau L$$

$P$ ดึงเฉพาะส่วนโหนด ความหมาย: ให้ทุกระดับสอดคล้องกันมากที่สุด โดยโหนดไม่หลุดจาก encoding เดิม

มีคำตอบเดียว (พิสูจน์, ChatGPT ข้อ 20): $Y^{\top}MY = \lVert x\rVert^2 + \tau Y^{\top}LY = 0$ บังคับ $x = 0$ และ $Y\in\ker L$ จากทฤษฎีบท 3 เส้นและ cell จึงเป็นศูนย์ด้วย ดังนั้น $M \succ 0$ (ตรวจแล้ว: ค่าเฉพาะต่ำสุด 0.37 บนกราฟทดสอบ)

ความหมายที่ระดับโหนด: แก้ค่า s, z ทันทีจะได้ $x^{\star} = (I + \tau S)^{-1}h$ โดย $S \succeq 0$ คือ operator ของโหนดหลังกำจัดตัวแปร น้ำหนักต่อความถี่ λ ของ S คือ $1/(1+\tau\lambda)$ ส่วนที่สอดคล้องกันอยู่แล้ว (λ = 0) ผ่านเต็ม

8.2 forward: preconditioned conjugate gradient (PCG)

input: h, operator Y ↦ M Y (ข้อ 7.2), preconditioner J = blockdiag(Pᵀ P + τ D)  # scalar per cell
Y ← Pᵀ h ; r ← Pᵀh − M Y ; z ← J⁻¹ r ; p ← z
repeat t = 1 … T_max:
    q ← M p ;  α ← (rᵀz)/(pᵀq) ;  Y ← Y + α p ;  r_new ← r − α q
    stop if ‖r_new‖ / ‖Pᵀh‖ ≤ tol
    z_new ← J⁻¹ r_new ; p ← z_new + ((r_newᵀ z_new)/(rᵀ z)) p ; r, z ← r_new, z_new
return x* = P Y

ตรวจแล้ว (กราฟ 24 โหนด):

  • PCG: 30 รอบได้ error 9e-6
  • Richardson ตามข้อ 20 ของ ChatGPT: 200 รอบได้ 1.6e-4 และ 400 รอบได้ 1e-7
  • condition number หลัง precondition = 27.5 บนกราฟใหญ่น่าจะสูงกว่านี้ ต้องวัด

8.3 backward: implicit gradient (ไม่ต้องเก็บทุกรอบ)

ให้ $\mathcal{L}$ เป็น loss และ $g = \partial\mathcal{L}/\partial x^{\star}$ แก้ระบบเดียวกันอีกครั้ง (M สมมาตร):

$$M\lambda = P^{\top}g,\qquad \frac{\partial\mathcal{L}}{\partial h} = P\lambda + (\text{ทางตรงผ่านหัวทำนาย}),\qquad \frac{\partial\mathcal{L}}{\partial\theta} = -\tau\,\lambda^{\top}\frac{\partial L}{\partial\theta}Y^{\star}$$

$\theta$ คือพารามิเตอร์ของ map, $a_e$ และ $\beta_f$ เทอมขวาสุดคำนวณได้โดยให้ autograd หาค่าของ $\lambda^{\top}L(\theta)Y^{\star}$ ที่ $Y^{\star}$ และ $\lambda$ คงที่ memory จึงเป็น O(state) ไม่ขึ้นกับจำนวนรอบ

ทางสำรอง: unroll T รอบแบบ Richardson หรือ PCG พร้อม checkpointing ง่ายกว่าแต่ memory ∝ T ข้อนี้ยังเปิดอยู่ใน D-B5

9. หัวทำนายและ loss

  • node classification: $\hat y_v = \mathrm{MLP}([h_v, x^{\star}_v])$ cross-entropy สำหรับ IMDB ใช้ BCE ต่อ genre และ threshold logit > 0 (spec F6)
  • link prediction: $z_v = \mathrm{GELU}(W[h_v, x^{\star}_v])$ แล้วใช้ dot product WISP สำหรับ LP (anchor บน message graph) ยังเป็น card ที่ค้างอยู่
  • graph classification (ภาคผนวก): ยังไม่ออกแบบ readout ไม่ต้องทำจนกว่าผู้เขียนสั่ง (spec 1.5)

การต่อ $h_v$ รับประกันแค่ว่า encoding เดิมยังอยู่ถึงหัวทำนาย ข้อนี้ใช้กับ A ได้เหมือนกัน จึงไม่ใช่เหตุผลว่า B ดีกว่า

10. mini-batch (ใช้การตัดสินใจ M0–M4 เดิม)

13. ต้นทุน

  • การใช้ M หนึ่งครั้ง: incidence โหนด–เส้น $2|E_P|$, เทอมตรง $|E_0|$, เส้น–cell $I_{ef} = \sum_f\ell_f$ แต่ละ incidence ใช้ map 1–3 ครั้ง ต้นทุนต่อครั้ง $O(kd + d^2)$ (frame ของ relation เป็น dense d×d ใช้ร่วมกัน) รวม $O\big((|E| + I_{ef})(kd + d^2)\big)$
  • state: $(N + |E_P| + F)\,d$ PCG ใช้ vector ราว 5 ชุด และ backward แบบ implicit ใช้อีกเท่ากัน memory ไม่ขึ้นกับจำนวนรอบ
  • เวลา: จำนวนรอบ PCG × การใช้ M หนึ่งครั้ง (forward) และอีกเท่ากัน (backward)

ACM โดยประมาณ (d = 64, float32; N = 10,942, facts 273,936, WISP cells 103,103, edge–cell incidences ≈ 411,257 − 103,103 = 308,154 จาก Part H H6):

  • ถ้า $E_P$ คือทุก fact state หนึ่งชุดมีขนาด (10,942 + 273,936 + 103,103) × 64 × 4 B ≈ 99 MB และ 10 ชุดประมาณ 1 GB
  • จำนวนเส้นจริงใน $E_P$ ยังไม่ได้นับ ทฤษฎีบท 7 ทำให้เส้นที่เหลือไม่ต้องมี state
  • เทียบกับ v2: state ของโหนด 2.8 MB ต่อชุด v3-B มี state ต่อชุดใหญ่กว่าราว 10–35 เท่า ขึ้นกับ $|E_P|$ (ประมาณ)
  • v1 ใช้ 9,260 MB ซึ่งน่าจะมาจาก map d×d ต่อ incidence (ยังไม่ตรวจ)

ต้องวัด: $|E_P|$ ต่อ dataset, จำนวนรอบ PCG ที่ tol = 1e-4, peak memory และเวลาต่อ epoch บน ACM, DBLP, IMDB ทั้งตอนรัน full batch และ mini-batch

14. test ที่ต้องเขียน (ค่า tolerance กำหนดใน card)

  1. functoriality: $R_{e_i,f}F_{v\triangleleft e_i} = T_{v,f}$ ทั้งสองปลายของทุก incidence บน draw จริง
  2. ไม่มีทิศ: กลับทิศที่เก็บของเส้นแล้ว $x^{\star}$ เท่าเดิม
  3. matrix-free เท่ากับ dense: ผลของ M Y จากข้อ 7.2 เท่ากับเมทริกซ์ dense บนกราฟเล็ก
  4. สมมาตรและไม่ติดลบ: $\langle Y_1, MY_2\rangle = \langle MY_1, Y_2\rangle$ และค่าเฉพาะต่ำสุดเป็นบวก
  5. kernel: map แบบ $R_eQ_v$ ทำให้ dim ker L = dim ker Δ₀ และแขน free_cell_maps ทำให้ยุบ
  6. ทฤษฎีบท 7: state ทุกเส้นกับ state เฉพาะ $E_P$ ให้ $x^{\star}$ เดียวกัน
  7. PCG: ลู่เข้าหาคำตอบ dense; residual ลดลงทุกรอบ
  8. implicit gradient: เทียบ finite difference และเทียบกับการ unroll
  9. ทางเข้าโหนด: รบกวน $z_f$ อย่างเดียว แล้ว A7 ต้องเปลี่ยน ส่วนโหนดนอก cell ที่ไม่ติดเส้นของ cell เปลี่ยนเฉพาะผ่านการแพร่ต่อ
  10. ไม่มี closure: ไม่มีเทอมใดของ M ที่เชื่อม $v_0$ กับ $v_\ell$ ตรง ๆ
  11. บาร์ ablation: แต่ละแขนในข้อ 11 รันได้ และ no_path_cells = ผลของ solve ที่ไม่มี cell
  12. mini-batch: batch ที่ไม่เชื่อมกันให้ผลเท่ากับรันทีละ scope; scope ทั้งกราฟให้ผลเท่ากับ full batch
  13. mutation: สลับ map ต้น/ปลาย, ลืม $\beta_f$, ใช้ local id กับชนิดที่ไม่มี feature ทุกข้อต้องมี test ที่ fail
