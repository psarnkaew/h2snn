## N2 — LP training negatives as HGB (K3)

## N4 — Stop conditions and failed trials (K5)

**Done.**
- `src/models/anchored_solve.py`: `NonFiniteLogWeightError` (condition `non_finite_log_weight`; value = the first non-finite `g(ξ_f)`) and `NonFiniteLossError` (condition `non_finite_loss`), both `StopConditionError` subclasses; `check_finite_loss(loss, epoch)`.
- `H2SNN._path_weights`: under the anchored model, `g(ξ_f)` is checked **before `exp`**; a non-finite value raises with the epoch of the forward. The anchored forward also tags a `PCGConvergenceError` (T_max) with condition `T_max`, value = limit = `T_max`, and the epoch, then re-raises it. The trainers' stop-condition logger logs T_max too (format of M6 kept).
- Non-finite training loss stops the run in every method: H2S-NN's NC, LP (per batch) and GC (per graph) trainers and the baselines' NC, LP and GC loops call `check_finite_loss` before `backward`.
- Tuners (the shared campaign engine `src/utils/wandb_campaign.py`, used by both `scripts/run_h2snn_wandb_tuning.py` and the baseline campaign): a trial that raises any of these is **failed**: the objective logs nothing under the sweep metric, so no score reaches the Bayesian search (the W&B run is marked failed and the search continues); the worker's status carries `failure = {condition, value, limit, epoch}` (`failure_details`); the parent records the attempt in `failures` with that dict (`record_failed_attempt`), keeps `failed_trials` and `failed_by_condition` (any other error counts as `other`) in the tuning state, writes `tuning_failures_<unit>.json`, and attaches the counts to each unit's result. Summaries count them: the baseline campaign's `summarize_cell` (per method and dataset: `failed_trials`, `failed_by_condition`) and the H2S-NN tuner's summary (per dataset).

**Failed-trial behaviour (VERIFIED-RUN, `tests/test_failed_trials.py`):** a fake trial raising each condition (`tau`, `log_weight_range`, `non_finite_log_weight`, `non_finite_loss`, `T_max`) through the real worker with a W&B stand-in: nothing logged to the search, no record written, the status names the condition, epoch and value, and the parent's accounting gives `failed_trials = 1` with that condition.

**Tests (VERIFIED-RUN).** New `tests/test_failed_trials.py` (5): forced NaN `g` raises `NonFiniteLogWeightError` with the epoch; the five conditions as above; an unrelated error is a failed trial counted as `other`; a NaN loss in the baselines' NC loop raises `NonFiniteLossError` at epoch 0 and maps to `non_finite_loss`; the baseline campaign summary sums failed trials and conditions per cell.
