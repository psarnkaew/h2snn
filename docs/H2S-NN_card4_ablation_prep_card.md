### K1 — Identity-map operator: arms S2 and S0 (spec 1.23 X-11, pre-registration §2)

### K2 — Proposal variance before tuning (B-10, spec 1.23 X-9b) — **runs before any H2S-NN tuning**
Port `docs/WISP_evidence/h3_variance_gate.py` to v3-B without changing its estimator: the fixed model is **trained to early stopping** on ACM, seed 1, central configuration `d` 32, `ℓ_max` 3, `r` 16, lr 1e-3, weight decay 1e-4, dropout 0.5, every other key at the protocol default (state each); `q` from that model's `w_f m_f` on one uniform draw (seed 43, detached); 20 training draws per proposal at equal `r` (seeds 1000–1019, same for both); 16 Rademacher probes (fixed seed); `V(q)` as in H3. **Gate (fixed):** `adaptive` is adopted iff `V(adaptive) ≤ 0.8 · V(uniform)`. Write `docs/card4_evidence/k2_variance_gate.json` (both V, ratio, the checkpoint's epoch, config). No accuracy is reported (the early-stopping metric is used, not written in the report).
**Consequence (fixed):** ratio > 0.8 → `uniform` stays (no code change). Ratio ≤ 0.8 → **stop the card's later tuning-related units and report**: switching to `adaptive` is an author decision and a config/validation change (`config.py:213`) made in a separate prompt.

### K3 — Known-answer S1′-B (C12, v3-B capacity) — warning signal stops the card
As the frozen pre-registration: `h5_synthetic.graph_s1p(n = 2000)`, `ℓ_max = 2`, `r = 640`, arms `full` + oracle and `covering_only` + oracle, β ∈ {0, log 64, log 512}, seeds 1–3 (18 runs); frozen settings (AdamW, no scheduler, no clip, lr 1e-3, scalar group constant 1e-2, 100 epochs, `d` 32, `tau_init` 1, `resample_paths: false`, 50/25/25 split, validation-accuracy selection). The oracle lives in `scripts/known_answer/` (never in `src/`). Write per run: test accuracy, relevant share of `D_P`, dispersion, final τ, `∂L/∂β` sign share. **Here the accuracy IS the pre-registered known-answer outcome and is reported** (synthetic task, not a performance number).
**Criteria (fixed, never loosened):** leak (β = 0 ≥ 0.9 in either arm) → no verdict, report; `full` + oracle < 0.9 on any seed at log 512 → **warning signal: stop the card and report** (no K4–K6); C12 part as the pre-registration states.

### K4 — Known-answer S3 (learnability of `g`)
Generator `scripts/known_answer/s3_graph.py`: length-4 chain P–A–B–C–Q (five types, four distinct relations, one schema), 64 cells per target, exactly one with `t_P ⊕ t_B ⊕ t_Q = 0` whose Q carries y, the other 63 parity 1 with an independent random class; every intermediate shared only within one target; tag balance as the pre-registration states (per-relation context means of tags independent of relevance). n = 2000, 50/25/25.
**Audit before any run (stop the unit if it fails):** (i) tag balance checked on the generated graph (state the statistic per relation); (ii) **fact-input probe:** on the training targets, a logistic probe predicting cell relevance from each fact's input `[h_u, c_u, h_v, c_v, rel]` (fixed solver and λ as K0 of Part K) has held-out accuracy within the binomial 99 % interval of chance; (iii) reachability as the frozen paragraph (log-weight gap ≈ log 512 must come from `g`).
**Runs:** arms `full`, `endpoints`, `uniform`, `full` + oracle (β = log 512), seeds 1–3 (12 runs), frozen settings; `ℓ_max = 4`, `r` such that coverage of the 64 cells per target is 1.0 (state the value and the coverage). Report per run: test accuracy, mean log-weight gap relevant − irrelevant.
**Criteria (fixed):** any control ≥ 0.9 or the probe above chance → leak, redesign (report, no verdict); `full` + oracle < 0.9 → capacity not shown on this graph; `full` ≥ 0.9 on 3/3 → passes; `full` ≤ 0.65 on all seeds → not shown at default settings (not a stop). Between: reported as is.

### K6 — Ablation driver (pre-registration §1, §2, §4.8)
`scripts/ablation/`: (1) **configurations (a):** for a dataset and `full`'s tuned configuration file (input), emit one resolved configuration per arm of §2 = `full` + the arm's one change; (2) **configurations (b):** for `endpoints`, `closure_only`, `instance_features`, `no_path_cells`, S2 a W&B sweep definition through the existing tuning launcher (plain Bayes, 100 trials, seed 0, space = §6's space restricted to keys that act in the arm, e.g. no `ℓ_max`, `r` for `no_path_cells`; state each arm's removed keys); (3) **seed runs:** seeds 1–10 per arm and configuration through `scripts/run_h2snn_runs.py`, reusing `full`'s seeds 1–4 from the main table (looked up, not re-run), every run keeping its best checkpoint and resolved configuration; (4) **parameter table** (§4.8): per arm on ACM, DBLP, IMDB, Freebase at `full`'s configuration: total and the removed/added part (`g`, geometry network, head input), `endpoints` within 5 % of `full`'s `g`; (5) a SLURM array script for (a) and (b) (`bash -n`, `sbatch --test-only`).

## Rules and stop conditions
- **What may run:** K2's training to early stopping (one run), K3–K5's synthetic runs (≈ 36 small), K6's one-epoch arm dry runs. Nothing else: no tuning, no seed runs on real data, no comparison of methods, no real-data metric in the report.
- **Cluster:** env `h2snn-b`; SLURM only (`srun --jobid=16741 --overlap` while held, else `sbatch`); `--mem`, `--time` set; job scripts print `git rev-parse HEAD`, `hostname`, `$SLURM_JOB_ID`. Known-answer runs may run as a job array on any free GPU.
- **Git:** one commit per unit, explicit paths; push `ablation-prep` after each unit; never push or move `v3b`, `design-docs` or another branch; never force-push, rebase, amend, stash or reset. Never stage `data/`, W&B folders, checkpoints, `Claude outputs/`, `H2S-NN/paper/`, vendor clones, `docs/lab-gpu-cluster.html`.
- **Forbidden:** changing a pre-registered expectation, tolerance, graph, seed or setting after a run; tuning anything in K3–K5; editing the spec, cards, pre-registrations or vendor code; silencing exceptions; deleting or skipping tests.
- **Stops the card:** K3 warning signal (`full` + oracle < 0.9 at log 512); K1 `full` not bit-identical. **Stop the unit (report, continue):** a §2 arm missing in code; K2 ratio ≤ 0.8 (author decision; K3–K6 continue); K4 audit fails (K5–K6 continue); a fix needs a file outside the list.
- **Not stop conditions:** a `full` miss on S3 (pre-registered reading); `log 64` results; time.
