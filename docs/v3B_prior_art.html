2. CCNN และ CTNN (Hajij et al.) CCNN: อ่าน Def. 16–29 จาก arXiv 2206.00606 ส่วนแรก; CTNN: บันทึก CTNN_copresheaf_notes.md ของโปรเจกต์ (อ่าน §3.2–5, App. B, C, E ไว้ 8 พ.ย.)

CCNN: ข้อความวิ่งตามเมทริกซ์เพื่อนบ้าน (incidence $B_{r,k}$, adjacency $A_{r,k}$, coadjacency) ด้วย push-forward แบบ convolution $K^j=GH^iW_G$ โดย $W_G$ เป็นพารามิเตอร์อิสระต่อชนิดเพื่อนบ้าน (ไม่ใช่ต่อ incidence) ไม่มีข้อบังคับความสอดคล้องใด ๆ ระหว่าง $W$ ของเพื่อนบ้านต่างชนิด บนตัวอย่าง: $h_{P1}\leftarrow\sum_{e\ni P1}W_{01}h_e+\sum_{f\ni P1}W_{02}h_f+\dots$

CTNN (copresheaf): เพิ่ม map $\rho_{y\to x}$ อิสระต่อ incidence และต่อทิศ ไม่มีข้อบังคับ ("without imposing sheaf consistency constraints") ชั้น (14) ใช้ขาเข้าเท่านั้น ⇒ operator ไม่สมมาตรโดยทั่วไป (บันทึก: eigenvalue เชิงซ้อน |Im λ| = 2.68 ในการตรวจ) และเป็น gradient step ก็ต่อเมื่อ $\rho_{x\to y}=\rho_{y\to x}^\top$ orthogonal

9. ถ้อยคำ novelty ที่ยืนได้ (สำหรับสไลด์)

พูดได้ (ทุกข้อชี้สมการได้):

  1. Path instances are cells of one sheaf with the graph: states on facts and on instances, maps on instances forced by the facts they traverse (Thm 1), so adding instances never destroys a consistent state of the graph (Thm 3). — ต่างจาก CWN/CTNN/SHN (map อิสระ) และ MAGNN/SGAT (instance เป็น feature)
  2. Instance information reaches every node of the instance, including intermediates, through its own facts and directly, with no endpoint shortcut (Thm 8; answers R2 W3) — ต่างจาก Hodge (Lemma A′), MAGNN, SGAT (target only)
  3. Who the intermediate node is enters the geometry (pair-conditioned maps ⇒ $T_{A7}$ depends on $h_{A7}$), not only the features — ต่างจาก MAGNN (relation-only rotations)
  4. One quadratic problem, unique solution for all parameter values, no propagation hyperparameter; the hub view (v2, SHN-like) and the covering-only view are configurations of the same model (Thm 7′) — ทำให้ ablation ที่ meta-review ขอเป็นการตั้งค่า ไม่ใช่โมเดลคนละตัว

ห้ามพูด: "first to use intermediate nodes" (MAGNN, SGAT ใช้); "sheaf-Hodge diffusion" (ไม่ใช่); "edge states carry new information" (ไม่มี edge feature; ต้องรอ C11); "novel solver" (คือ PPR); "no prior sheaf on cell complexes with learned maps" (2606.00937 มี — ต่างที่ map บังคับ/โดเมน แต่ต้องอ่านเต็มก่อน)
