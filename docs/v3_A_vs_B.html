6. ส่วนที่ A และ B ใช้ร่วมกัน (มาจาก v2 / spec v1.7)

6.1 แปลง feature ของโหนด

แต่ละชนิดโหนดมีตัวแปลงของตัวเอง เพื่อให้ทุกโหนดอยู่ในพื้นที่ d มิติเดียวกัน:

$$h_0(v) = \mathrm{TypeEncoder}_{\phi(v)}(x_v), \qquad c(v) = \text{ค่าเฉลี่ยของ } h_0 \text{ เพื่อนบ้านแยกตาม (relation, บทบาท)}$$

6.2 map ของเส้น (หมุนพิกัด)

สำหรับเส้น e ที่มีชนิด ψ(e) และโหนด v ในบทบาท role ∈ {ต้น, ปลาย}:

$$F_{v\triangleleft e} = R_{\psi(e),\,\mathrm{role}}\; H_k(u)\cdots H_1(u), \qquad H_i(u) = I - 2\frac{u_i u_i^{\top}}{\lVert u_i\rVert^2}, \qquad u = \mathrm{MLP}\big([h_v, h_{\text{other}}, \mathrm{rel}_{\psi(e)}, \mathrm{role}]\big)$$

$F$ เป็นการหมุนหรือสะท้อน ความยาวไม่เปลี่ยน ($F^{-1} = F^{\top}$) ขึ้นกับทั้งสองปลายและชนิดเส้น และคำนวณครั้งเดียว ไม่คำนวณใหม่ทุกรอบ แต่ละเส้นมี scale หนึ่งค่าคือ $c_e$ เก็บ $k\cdot d$ ตัวเลขต่อ incidence แทน $d^2$

6.3 transport (บังคับโดยเส้นจริง)

สำหรับ path $f = (v_0, e_1, v_1, \dots, e_\ell, v_\ell)$ โดย $v_0$ คือโหนดต้นที่ WISP เริ่มเดิน:

$$T_{v_0} = I, \qquad T_{v_i} = T_{v_{i-1}}\, F_{v_{i-1}\triangleleft e_i}^{\top}\, F_{v_i\triangleleft e_i}$$

บนตัวอย่าง:

$$T_{P1} = I, \qquad T_{A7} = F_{P1\triangleleft e_0}^{\top}F_{A7\triangleleft e_0}, \qquad T_{P9} = T_{A7}\,F_{A7\triangleleft e_1}^{\top}F_{P9\triangleleft e_1}$$

$T_{A7}$ ขึ้นกับ map ของ e0 ซึ่งคำนวณจาก $h_{A7}$ นี่คือช่องทางที่ "A7 เป็นใคร" เข้าไปในเรขาคณิตของ cell transport ไม่มีพารามิเตอร์ของตัวเอง

map จากเส้นไป cell ที่ซ่อนอยู่คือ $F_{e_i\triangleleft f} = T_{v_{i-1}}F_{v_{i-1}\triangleleft e_i}^{\top}$ ซึ่งทำให้

$$F_{e_i\triangleleft f}F_{v_{i-1}\triangleleft e_i} = T_{v_{i-1}}, \qquad F_{e_i\triangleleft f}F_{v_i\triangleleft e_i} = T_{v_i}$$

6.4 WISP: path ไหนเข้า และหนักเท่าไร

เดินสุ่มจากโหนดเป้าหมาย: สุ่มความยาว ℓ ∈ {2,…,ℓ_max} แล้วแต่ละก้าวสุ่มชนิดเส้นที่ยังไปโหนดที่ไม่เคยเดินได้ แล้วสุ่มโหนดถัดไป ได้ 1 walk = 1 cell

$$p(\omega) = \frac{1}{\ell_{\max}-1}\prod_{j=1}^{\ell}\frac{1}{|A_j|}\cdot\frac{1}{|N_j^{\text{unvisited}}|}, \qquad m_f = \sum_{\omega\to f}\frac{1}{r}\cdot\frac{p(\omega)}{\tfrac12 p(\omega)+\tfrac12 q(\omega)} \le \frac{2}{r}\ \text{ต่อ walk}$$
$$w_f = \exp\!\big(g(\xi_f)\big), \qquad \xi_f = [h_0(v_0),\dots,h_0(v_\ell),\ \mathrm{rel}(a_1),\dots,\mathrm{rel}(a_\ell)]$$

น้ำหนักรวมของ cell คือ $w_f m_f$ โดย $m_f$ มาจากการสุ่ม (ไม่ลำเอียง, spec Prop. S) และ $w_f$ เรียนรู้จาก path ทั้งเส้น walk ไม่ซ้ำโหนด (ตรวจในโค้ด wisp_sampler.py ใช้ unvisited)

6.5 gate, filter, หัวทำนาย

ทั้งสองทางใช้รูปแบบเดียวกัน ต่างกันแค่ $\hat\Delta$ (ข้อ 7 และ 8):

$$\mathcal{A} = G\,\hat\Delta\,B, \qquad G = \mathrm{diag}(g), \; B = \mathrm{diag}(b), \qquad Y = \sum_{k=0}^{K} \mathcal{T}_k(\mathcal{A} - I)\,(I\otimes W_k)\,Y_0, \qquad \sum_k \lVert W_k\rVert_2 \le 1$$
$$\hat y_v = \mathrm{MLP}\big([\,x_v,\ h_0(v)\,]\big)$$

$\mathcal{T}_k$ คือ Chebyshev polynomial การแพร่เป็นเชิงเส้นทั้งหมด ส่วนที่ไม่เป็นเชิงเส้นอยู่ที่หัวทำนาย (spec L3) gate และ map คำนวณครั้งเดียว (spec R10)

8. ทาง B v2 + ชั้น edge: สมการ

state มี 3 ระดับ: $Y = (x, s, z)$ โดย $x \in \mathbb{R}^{Nd}$ อยู่ที่โหนด, $s \in \mathbb{R}^{Ed}$ อยู่ที่เส้นจริงทุกเส้น และ $z \in \mathbb{R}^{Id}$ อยู่ที่ cell ทุกตัวที่ WISP สุ่มได้ closure edge อยู่ในนิยามของ complex (ทำให้ path เป็น 2-cell จริงและใช้ในบทพิสูจน์) แต่ไม่มี state และไม่อยู่ใน energy (ทฤษฎีบท 1b) เหมือนทาง A

8.1 energy ตัวเดียว: "แต่ละสิ่งควรตรงกับชิ้นส่วนที่ติดกับมันหลังหมุน"

$$E_B(x,s,z) = \underbrace{\frac12\sum_{e=(u,v)} c_e^2\Big(\big\lVert F_{u\triangleleft e}x_u - s_e\big\rVert^2 + \big\lVert F_{v\triangleleft e}x_v - s_e\big\rVert^2\Big)}_{\text{โหนด–เส้น}} \;+\; \underbrace{\frac12\sum_{f} w_f m_f\sum_{e\in\partial f}\big\lVert F_{e\triangleleft f}s_e - z_f\big\rVert^2}_{\text{เส้น–cell}}$$

$F_{e\triangleleft f} = T_{v_{i-1}}F_{v_{i-1}\triangleleft e_i}^{\top}$ มาจากข้อ 6.3 ทุกคู่ที่ติดกัน (โหนดกับเส้น, เส้นกับ cell) มีเทอมรูปเดียวกัน แผนภาพที่เชื่อมแต่ละสิ่งกับสิ่งที่อยู่ติดกันในทางคณิตศาสตร์เรียกว่า Hasse diagram

8.2 operator (block)

$$L_B = \nabla^2 E_B = \begin{bmatrix} D_x & -S^{\top} & 0 \\ -S & D_s & -C^{\top} \\ 0 & -C & D_z \end{bmatrix}$$
  • block โหนด–เส้น: $S_{e,v} = c_e^2 F_{v\triangleleft e}$
  • block เส้น–cell: $C_{f,e} = w_f m_f F_{e\triangleleft f}$
  • ค่าบนแนวทแยง: $D_x(v) = \sum_{e\ni v}c_e^2$, $D_s(e) = 2c_e^2 + \sum_{f\ni e}w_f m_f$, $D_z(f) = w_f m_f\,\ell_f$
$$\hat\Delta_B = D^{-1/2}L_B D^{-1/2}, \qquad \sigma(\hat\Delta_B) \subset [0,2]$$

8.3 ค่าเริ่มต้น และสิ่งที่หัวทำนายอ่าน

$$x^{(0)} = h_0, \qquad s_e^{(0)} = \tfrac12\big(F_{u\triangleleft e}h_0(u) + F_{v\triangleleft e}h_0(v)\big), \qquad z_f^{(0)} = \frac{1}{\ell_f}\sum_{e\in\partial f}F_{e\triangleleft f}\,s_e^{(0)}$$

9.1 ทฤษฎีบท 1: โครงสร้างของเราเป็น cellular sheaf บน 2-cell complex

complex $X$:

  • ระดับ 0 คือโหนด
  • ระดับ 1 คือเส้นจริง $E$ และ closure edge หนึ่งเส้นต่อ path $c_f = (v_\ell \to v_0)$
  • ระดับ 2 คือ path ที่ WISP สุ่มได้ ขอบของแต่ละ path คือ $\partial f = (e_1,\dots,e_\ell,c_f)$ ซึ่งเป็นวงปิด จึงเป็น 2-cell จริงในความหมายของ cell complex

sheaf $\mathcal{F}$: ทุกสิ่งมีพื้นที่ $\mathbb{R}^d$ และทุกคู่ "อยู่ติดกัน" $\sigma \triangleleft \tau$ มี map หนึ่งตัว:

$$F_{v\triangleleft e}\ \text{(เรียนรู้)},\quad F_{e_i\triangleleft f} = T_{v_{i-1}}F_{v_{i-1}\triangleleft e_i}^{\top},\quad F_{v_0\triangleleft c_f} = I,\quad F_{v_\ell\triangleleft c_f} = T_{v_\ell},\quad F_{c_f\triangleleft f} = I,\quad F_{v\triangleleft f} := T_v$$

ข้อความ: map เหล่านี้ประกอบกันได้โดยไม่ขัดกัน (functoriality) คือทุกลำดับ $v \triangleleft e \triangleleft f$ ให้ผลเดียวกับการไปตรง $v \triangleleft f$:

$$F_{e\triangleleft f}\,F_{v\triangleleft e} = F_{v\triangleleft f}\qquad \text{สำหรับทุก } v\in e\in\partial f$$

พิสูจน์:

  • เส้นจริง $e_i$ ที่ปลายต้น: $F_{e_i\triangleleft f}F_{v_{i-1}\triangleleft e_i} = T_{v_{i-1}}F^{\top}F = T_{v_{i-1}}$
  • ปลายท้าย: $F_{e_i\triangleleft f}F_{v_i\triangleleft e_i} = T_{v_{i-1}}F_{v_{i-1}\triangleleft e_i}^{\top}F_{v_i\triangleleft e_i} = T_{v_i}$ ตามนิยามของ transport
  • closure: $I\cdot I = T_{v_0}$ และ $I\cdot T_{v_\ell} = T_{v_\ell}$
  • โหนดกลาง $v_i$ อยู่บนสองเส้น ($e_i$, $e_{i+1}$) ทั้งสองทางให้ $T_{v_i}$ เหมือนกัน และเพราะ path ไม่ซ้ำโหนด แต่ละโหนดจึงมี $T_v$ เพียงค่าเดียว ∎

ตัวอย่าง: A7 เข้า f1 ผ่าน e0 ได้ $F_{e_0\triangleleft f_1}F_{A7\triangleleft e_0} = T_{A7}$ และผ่าน e1 ได้ $F_{e_1\triangleleft f_1}F_{A7\triangleleft e_1} = T_{A7}$ ค่าเดียวกัน

ตรวจ: residual สูงสุดบนทุกลำดับ รวม closure = 7e-16

map ไม่มีทางเลือกอื่น: ถ้ากำหนดกรอบของ cell ที่ $v_0$ แล้ว เงื่อนไขข้างบนบังคับ $F_{e_i\triangleleft f}$ ทีละก้าว (spec Prop. 1) cell จึงไม่มีพารามิเตอร์ของตัวเอง

ทฤษฎีบท 1b (ตัด closure ออกจากการคำนวณได้โดยไม่เสียอะไร): ให้ $X'$ คือ $X$ ที่ไม่มี closure global section (state ที่ทุกคู่ติดกันตรงกันหลังแปลง) บน $X$ กับบน $X'$ จับคู่กันได้หนึ่งต่อหนึ่ง

พิสูจน์:

  • จาก $X$ ไป $X'$: ตัดค่าของ closure ทิ้ง
  • จาก $X'$ ไป $X$: ให้ $s_{c_f} := x_{v_0}$ ค่านี้ตรงกับปลาย $v_0$ เพราะ $F_{v_0\triangleleft c_f} = I$ ตรงกับปลาย $v_\ell$ เพราะ $T_{v_\ell}x_{v_\ell} = T_{v_0}x_{v_0} = x_{v_0}$ (cell ตรงกันทุกโหนด) และตรงกับ cell เพราะ $F_{c_f\triangleleft f}s_{c_f} = x_{v_0} = z_f$
  • ค่านี้ถูกบังคับให้เป็นค่าเดียว ∎

ดังนั้น closure อยู่ในนิยามเพื่อให้ path เป็น 2-cell จริงและเพื่อบังคับ map แต่การแพร่ไม่ต้องให้ closure มี state และไม่มีเส้นปลาย-ปลายให้ข้อมูลเดิน

9.2 ทฤษฎีบท 2: วงรอบ cell ไม่หมุน (holonomy = I)

ข้อความ: เดินจาก $v_0$ ไปตาม path ถึง $v_\ell$ แล้วกลับทาง closure การหมุนรวมคือ

$$\underbrace{T_{v_0}^{-1}T_{v_\ell}}_{\text{ตาม path}}\cdot\underbrace{\big(F_{v_\ell\triangleleft c_f}\big)^{-1}F_{v_0\triangleleft c_f}}_{\text{กลับทาง closure}} = T_{v_\ell}\,T_{v_\ell}^{-1} = I$$

พิสูจน์: แทนค่าจากนิยามใน 9.1 ∎

ความหมาย: cell ไม่ได้เพิ่มข้อบังคับใหม่ให้กราฟ ต่างจากวงจริงในกราฟ (เช่น P1–A7–P9–A8–P1) ซึ่ง holonomy ไม่เป็น I ได้ตามที่ map เรียนรู้ เหมือน NSD

9.3 ทฤษฎีบท 3: cell ไม่ทำให้ข้อมูลยุบ

ให้ $\mathcal{L}_A = \Delta_0 + L_P$ (ทาง A) และ $L_B$ (ทาง B) "ข้อมูลยุบ" หมายถึงชุดของ state ที่การแพร่ไม่ทำลาย (kernel) เล็กลง

ข้อความ:

$$\ker\mathcal{L}_A = \ker\Delta_0, \qquad \ker L_B = \big\{(x,\,s,\,z)\;:\; x\in\ker\Delta_0,\ s_e = F_{u\triangleleft e}x_u,\ z_f = T_v x_v\big\} \cong \ker\Delta_0$$

พิสูจน์ (A):

  1. $E_A$ เป็นผลรวมของกำลังสอง จึงเป็นศูนย์ก็ต่อเมื่อทุกเทอมเป็นศูนย์
  2. เทอมของเส้นเป็นศูนย์ทุกเส้น หมายความว่า $\delta_0x = 0$
  3. เมื่อ $\delta_0x = 0$ บนเส้น $e_i$ ของ path จะได้ $T_{v_i}x_{v_i} = T_{v_{i-1}}F_{v_{i-1}\triangleleft e_i}^{\top}F_{v_i\triangleleft e_i}x_{v_i} = T_{v_{i-1}}F_{v_{i-1}\triangleleft e_i}^{\top}F_{v_{i-1}\triangleleft e_i}x_{v_{i-1}} = T_{v_{i-1}}x_{v_{i-1}}$
  4. ทุกโหนดของ path จึงมี $T_vx_v$ เท่ากัน เทอมของ cell เป็นศูนย์เอง
  5. สรุป: cell ไม่เพิ่มเงื่อนไขใด ∎

9.4 ทฤษฎีบท 4: มี state ที่แยก class ได้สมบูรณ์ และไม่ถูกการแพร่ทำลาย แม้เพื่อนบ้านต่าง class

ข้อความ: สำหรับการแบ่ง class $y: V\to\{1,\dots,C\}$ แบบใดก็ได้ และ vector หนึ่งหน่วย $a_1,\dots,a_C$ ที่ต่างกันใน $\mathbb{R}^d$ ($d \ge 2$) มี map ของเส้น (แต่ละตัวเป็น $I$ หรือการสะท้อนหนึ่งครั้ง) ที่ทำให้

$$x^{\star}_v = a_{y(v)}$$

เป็น global section และอยู่ใน kernel ของทั้ง A และ B ข้อนี้เป็นจริงบนกราฟใดก็ได้ ไม่ว่าจะมีวงหรือมี heterophily มากแค่ไหน

พิสูจน์:

  1. สำหรับเส้น $e = (u,v)$ ให้ $F_{u\triangleleft e} = I$ และ $F_{v\triangleleft e} = H(a_{y(v)}\to a_{y(u)})$ โดย $H(a\to b) = I - 2\frac{(a-b)(a-b)^{\top}}{\lVert a-b\rVert^2}$ ซึ่งเป็นการสะท้อนที่ส่ง $a$ ไป $b$
  2. จะได้ $F_{v\triangleleft e}x^{\star}_v = a_{y(u)} = F_{u\triangleleft e}x^{\star}_u$ ทุกเส้น จึงได้ $\delta_0x^{\star} = 0$
  3. จากทฤษฎีบท 3 $x^{\star}$ อยู่ใน kernel ของ A และ B ด้วย
  4. class ต่างกันได้ vector ต่างกัน และจุดบนทรงกลมหนึ่งหน่วยแต่ละจุดแยกจากจุดอื่นได้ด้วยระนาบ (เป็นจุดยอดของ convex hull) แต่ละ class จึงแยกออกด้วยตัวแบ่งเชิงเส้นได้ ∎

ตัวอย่าง: P1 อยู่ class X ($a_X$) และ P9 อยู่ class Y ($a_Y$) ส่วน A7 (author ไม่มี label) ได้ vector ใดก็ได้ เช่น $a_X$ ให้ $F_{A7\triangleleft e_0} = I$, $F_{P1\triangleleft e_0} = I$ และบน $e_1$ ให้ map ของ P9 สะท้อน $a_Y$ ไป $a_X$ ผลคือทุกเส้น "ตรงกัน" แต่ P1 กับ P9 ยังต่างกันชัดเจน และ cell f1 ก็ตรงกันด้วย ($T_vx^{\star}_v$ เท่ากันทั้งสามโหนด)

ตรวจ: $\lvert\delta_0x^{\star}\rvert$ = 2e-16, $\lvert\mathcal{L}_Ax^{\star}\rvert$ = 2e-15, $\lvert L_B(x^{\star}, Fx^{\star}, Tx^{\star})\rvert$ = 2e-15 บนกราฟที่ 29 จาก 48 เส้นเชื่อมโหนดต่าง class

ความหมาย: การแพร่บน sheaf ผลักให้ "ค่าหลังแปลงเข้าภาษาของเส้น" ตรงกัน ไม่ได้ผลักให้ค่าของโหนดเท่ากัน จุดนิ่งจึงรวม state ที่แยก class ได้สมบูรณ์ ต่างจาก graph Laplacian ธรรมดา ($F = I$) ที่จุดนิ่งมีแต่ค่าคงที่

เงื่อนไขเพิ่มเมื่อใช้ map ของเราจริง ($F = R_{\psi,\mathrm{role}}H_k\cdots H_1(u)$)

  1. จำนวนการสะท้อน k ต้องพอ: การหมุนหรือสะท้อนใด ๆ ใน $\mathbb{R}^d$ เขียนเป็นการสะท้อนไม่เกิน d ครั้งได้ (Cartan–Dieudonné) ถ้า k น้อยกว่า d บาง map จะสร้างไม่ได้
  2. class ต้องอ่านได้จาก input ของ MLP ($h_v$, $h_{\text{other}}$, ชนิดเส้น, บทบาท) ถ้าโหนดสองตัว input เหมือนกันทุกอย่างแต่ class ต่างกัน ก็ได้ map เดียวกัน ข้อจำกัดนี้มีในทุก GNN

สิ่งที่ไม่ได้พิสูจน์: การเทรนจะหา map เหล่านี้เจอ ทฤษฎีบทนี้บอกว่ามีอยู่ในชุดของโมเดล เหมือนที่ NSD พิสูจน์ได้เพียงว่ามีอยู่

9.5 ทฤษฎีบท 5: ถ้าแพร่จนนิ่ง ทุกโหนดได้ภาพรวมของทั้งกราฟในพิกัดของตัวเอง

ให้การแพร่แบบความร้อน $\dot x = -\mathcal{L}x$ จะได้ $x(t) = e^{-t\mathcal{L}}x(0) \to P_{\ker\mathcal{L}}\,x(0)$ เมื่อ $t\to\infty$ (การฉายตั้งฉากลง kernel) เพราะ $\mathcal{L}$ สมมาตรและไม่ติดลบ

ข้อความ: สำหรับ sheaf ที่ไม่หมุนทั้งกราฟ $F_{v\triangleleft e} = R_eQ_v$ บนกราฟที่เชื่อมกัน ไม่ว่าจะมี cell หรือไม่ (ทาง A)

$$x_v(\infty) = Q_v^{\top}\,\bar y, \qquad \bar y = \frac{1}{N}\sum_{u\in V}Q_u\,x_u(0)$$

พิสูจน์:

  1. $\ker\Delta_0 = \{x : x_v = Q_v^{\top}y,\ y\in\mathbb{R}^d\}$ เพราะ $F_{u\triangleleft e}x_u = R_eQ_uQ_u^{\top}y = R_ey = F_{v\triangleleft e}x_v$ และมิติเท่ากับ $d$ บนกราฟที่เชื่อมกัน
  2. ฐาน $b_i = \frac{1}{\sqrt N}(Q_v^{\top}e_i)_{v\in V}$, $i = 1..d$ ตั้งฉากกันและยาวหนึ่ง เพราะ $Q_v$ เป็นการหมุน
  3. $P x = \sum_i b_ib_i^{\top}x = \big(Q_v^{\top}\tfrac{1}{N}\sum_u Q_ux_u\big)_v$
  4. จากทฤษฎีบท 3 cell ไม่เปลี่ยน kernel ลิมิตจึงเหมือนเดิม ∎

ความหมาย: ทุกโหนดได้ค่าเฉลี่ยของทั้งกราฟ ($\bar y$ ใช้ทุกโหนด) แต่แสดงในพิกัดของตัวเอง ($Q_v^{\top}$) ตัวตนของโหนดจึงไม่หายไป ทั้งที่ได้ข้อมูลจากทั้งกราฟ

ตรวจ: ลิมิตจริงต่างจากสูตร 0 ทั้งแบบไม่มีและมี cell ส่วนทาง B ส่วนโหนดของลิมิตเป็น global section ($\lvert\delta_0x\rvert$ = 0, ขนาด 0.53) แต่จุดที่ได้ขึ้นกับค่าเริ่มของเส้นและ cell ด้วย ยังไม่มีสูตรปิด

ทฤษฎีบท 5b (ทาง A: cell ทำให้ไปถึงภาพรวมเร็วขึ้น):

$$\lambda^{+}_{\min}(\Delta_0 + L_P) \;\ge\; \lambda^{+}_{\min}(\Delta_0)$$

พิสูจน์: kernel เท่ากัน (ทฤษฎีบท 3) สำหรับ $x$ ที่ตั้งฉากกับ kernel จะได้ $x^{\top}(\Delta_0+L_P)x \ge x^{\top}\Delta_0x \ge \lambda^{+}_{\min}(\Delta_0)\lVert x\rVert^2$ เพราะ $L_P \succeq 0$ ∎

ตรวจ: 0.763 → 0.865

โมเดลไม่ได้แพร่จนถึงลิมิต ใช้ filter ดีกรี K ซึ่งรวมการแพร่ทีละก้าวไว้เป็นกรณีพิเศษ (spec Prop. 7) ทฤษฎีบท 5 จึงบอกว่าโมเดล "ทำได้" ถ้าต้องการภาพรวม ไม่ได้บอกว่าโมเดลทำแบบนั้นเสมอ filter ยังเลือกเก็บส่วนที่ยังไม่ตรงกันไว้ได้ ซึ่งช่วยเมื่อข้อมูลเป็น heterophily
